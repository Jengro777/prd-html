在本指南中，我们将向你展示如何迁移到 Paystack UI，它是 UI 组件和方法的集合，允许你在 Android 应用程序中受理支付。

有什么新消息

Paystack UI 是从头开始构建的，旨在解决前 SDK 的痛点：

  1. 可扩展性：此前，我们的SDK仅支持卡作为支付渠道。我们使用模块化架构构建了新的SDK，允许我们添加可用的支付渠道。
  2. 更好UX：SDK为UI组件提供了更简洁的外观和直观的支付体验。
  3. 安全：交易现在从后端发起并在移动应用程序上完成，让开发者完全控制。
  4. 改进DX：我们公开了直观的APIs，让你可以编写更少的代码行以获得更快的结果

更新依赖项

使用 Paystack UI 的第一步是将其添加到你的依赖项列表中：

  • 构建.gradle
dependencies {
// remove this
implementation 'co.paystack.android:paystack:3.1.2'
// add this
implementation 'com.paystack.android:paystack-ui:0.0.9'
}

不要忘记同步项目以拉入库。

成功安装依赖项后，你现在可以将库导入到你的项目中：

import com.paystack.android.core.Paystack
import com.paystack.android.ui.paymentsheet.PaymentSheet

SDK 需要初始化才能使用，所以这是我们要做的第一个代码更改：

PaystackSdk.initialize(applicationContext)

与之前的SDK不同，PaystackUI使用构建器模式来构建对象。

回调

回调用于管理SDK端的后支付流程。这就是你管理交易最终状态的方式。

PaystackSdk.chargeCard(this, charge, object : TransactionCallback {
override fun onSuccess(transaction: Transaction) {
Log.d("Main Activity", "onSuccess: " + transaction.getReference);
}

override fun beforeValidate(transaction: Transaction) {
Log.d("Main Activity", "beforeValidate: " + transaction.reference)
}

override fun onError(error: Throwable, transaction: Transaction) {
Log.d("Main Activity", "onError: " + error.localizedMessage)
Log.d("Main Activity", "onError: $error")
}
})

PaystackUI

private fun paymentComplete(paymentSheetResult: PaymentSheetResult) {
val message = when (paymentSheetResult) {
PaymentSheetResult.Cancelled -> "Cancelled"
is PaymentSheetResult.Failed -> {
Log.e("Something went wrong", paymentSheetResult.error.message.orEmpty(), paymentSheetResult.error)
paymentSheetResult.error.message ?: "Failed"
}

is PaymentSheetResult.Completed -> {

Log.d("Payment successful", paymentSheetResult.paymentCompletionDetails.toString())
"Successful"
}
}
}

我们将 TransactionCallback 替换为 PaymentSheetResult，它公开了三种状态：Failed、Cancelled 和 Completed，可用于管理后支付流程。

受理支付

以前，受理支付需要你创建 Card 和 Charge 对象的实例。使用 Paystack UI，你可以使用 初始化交易API 接口从服务端初始化交易，并使用返回的 access_code 来触发 PaymentSheet，如下所示：

val cardNumber = "4084084084084081"
val expiryMonth = "11"
val expiryYear = "24"
val cvv = "408"

val card = Card(cardNumber, expiryMonth, expiryYear, cvv)

val charge = Charge()
charge.card = card

PaystackUI

private lateinit var paymentSheet: PaymentSheet

override fun onCreate(savedInstanceState: Bundle?) {
super.onCreate(savedInstanceState)


paymentSheet = PaymentSheet(this, ::paymentComplete)
}

private fun makePayment() {

paymentSheet.launch("access_code")
}

结论

最后，你可以删除卡片活动或片段以及任何其他补充你之前创建的 UI 的代码。你可以查看 参考页 了解有关 Paystack UI 上可用的方法和 UI 组件的更多信息。
