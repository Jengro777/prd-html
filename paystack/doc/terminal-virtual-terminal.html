使用手机接受当面付款并通过 Whatsapp 接收付款通知

简介

虚拟终端将手机转变为销售点系统，使企业无需专用的POS硬件即可受理支付。通过将支持 WhatsApp 的手机连接到虚拟终端，你可以立即设置支持银行转账和QR代码支付的支付点。

虚拟终端非常适合：

  • 希望最大限度降低前期成本的小型企业
  • 需要灵活支付选项的移动供应商
  • 希望快速设置额外支付点的企业
  • 接受货到付款的送货商户

创建虚拟终端

要创建虚拟终端，请向 虚拟终端API 发出 POST 请求，指定名称和最多 5 个支持 WhatsApp 的电话号码。

curl "https://api.paystack.co/virtual_terminal"
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{
"name": "Sales Point #1",
"destinations": [
{"target": "+2347081234567"}
]
}'
-X POST
{
  "status": true,
  "message": "Virtual Terminal created",
  "data": {
    "id": 26677,
    "name": "Sales Point #1",
    "integration": 353514,
    "domain": "live",
    "code": "VT_L837PT5K",
    "paymentMethods": [
      {
        "dedicated_nuban_id": 26196910,

        "account_number": "9964842038",

      {
        "target": "2347081234567",
        "type": "whatsapp",
        "name": null
      }
    ],
    "currency": "NGN"
  }
}

创建后，终端即可通过其独特的付款页面或专用付款详细信息（如果适用）受理支付。

受理支付

创建虚拟终端后，你可以根据你的市场通过两种方式与客户共享：

使用 Paystack 生成的海报

Paystack 会自动为你的虚拟终端生成海报，你可以下载该海报并在你的营业地点显示。海报上包含一个QR代码，客户可以扫描该代码来访问终端的支付页面。

在支付页面，客户可以使用PaystackCheckout完成交易，Paystack支持银行卡、银行转账、手机钱等多种在线支付方式。

要将海报用于你的虚拟终端：

  1. 导航至终端选项卡：登录你的PaystackDashboard并转到终端选项卡。
  2. 选择虚拟终端：选择你要下载海报的虚拟终端。
  3. 下载海报：在终端详情中，点击“海报”选项。选择你想要使用的海报版本并下载。
  4. 展示海报：将海报放置在客户可以轻松访问的显眼位置。

使用专用的付款详细信息

在支持的市场中，每个虚拟终端都分配有唯一的付款详细信息，允许客户进行直接转账：

  • 尼日利亚：专属虚拟账户
  • 肯尼亚：M-Pesa 工资单
  • 加纳：USSD代码。

客户可以使用这些付款详细信息将资金直接转入你的终端。这些详细信息包含在创建终端时的 API 响应中，并且也显示在海报上以方便参考。

{

      "bank": "Paystack-Titan"
    }
  ]
}

处理通知

当向你的虚拟终端付款时，你可以收到实时通知，以便随时了解情况并有效处理交易。 Paystack 提供两种通知选项：

Whatsapp 通知

成功付款后，每个注册的 Whatsapp 号码都会收到针对终端进行的所有交易的即时付款通知。
