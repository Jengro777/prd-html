API 变更日志

通过收回本来会损失的资金来增加你的收入

简介

通过此功能，当尝试充值失败且资金不足时，我们将自动以可充值的最大金额重试。例如，如果你尝试向某人收取 NGN 10,000，但他们的账户中只有 NGN 4,000，从历史上看，交易将失败并显示 insufficient funds，但对于部分借记，我们将收取大约 NGN 3,900，

部分借记目前仅适用于Mastercard和Verve

谁可以使用这个？

此功能仅应要求提供。一旦我们的审核团队批准，你将获得访问权限。请联系hello@paystack.com请求访问。

它是如何运作的？

你只能使用此功能对现有授权进行收费。有两种使用方法。通过 部分借方 API 接口或我们的 批量充电API 接口。

使用批量充值接口时需要传递flag"attempt_partial_debit" : true

校验交易

当校验涉及部分借记的交易（或实现Webhook）时，会返回两种类型的金额：

参数描述
金额这是向客户收取的金额（以 支持的货币 子单位表示）
requested_amount这是你打算收取的金额 支持的货币。
