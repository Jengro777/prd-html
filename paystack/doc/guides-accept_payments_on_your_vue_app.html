需要开始通过你的 Vue 应用程序受理支付？在本文中，我们将探讨如何将 Paystack 与你的 Vue 应用程序连接。我们将在演示的捐赠表格上使用示例结账页面

简介

我们将在这个演示中使用我们的公钥。你可以在 PaystackDashboard 的 API 密钥和 Webhook 部分或 薪资画布 的 开发者概览 页面中找到你的 API 键。

你会注意到你有两个公钥：测试和实时。在构建应用程序时，最好使用测试密钥，因为这将允许你模拟交易。一旦你的应用程序准备好投入生产，你就可以切换到实时密钥。

由于这是客户端集成，这意味着我们的 API 密钥将被公开。为了防止任何人访问我们的 Paystack 账户，我们希望确保使用我们的 公钥。密钥只能在服务端上使用。

项目设置

如果你已经熟悉Vue，那么本节对你来说会非常熟悉，你可以跳到下一节安装Paystack。如果没有，VueJS 是一个用于构建前端应用程序的 JavaScript 库。使用 Vue 构建大型应用程序时，NPM 和 Yarn 是流行的安装方法。

npm install -g @vue/cli

yarn global add @vue/cli

安装后，导航到所需的文件夹并创建一个新的 Vue 项目；

vue create project_name

终端会显示一些预设配置，作为初学者，建议选择默认配置。这将在当前目录中创建一个示例项目project_name。出于本指南的目的，我将创建一个简单的慈善表格来收集用户名、邮箱地址并接受捐赠者的付款。

安装Paystack

现在添加 Paystack Vue 包，此包包含 Paystack Inline JS 库和作为单个组件的结账。将此插件添加到你的 vue 项目中；

npm install vue-paystack --save

安装后，将库导入到你的 App.vue 文件中，如下所示

<script>
import paystack from 'vue-paystack';

export default {
name: "App",
components: {
paystack
},
data: () => {
return {
amount: null,
full_name: null,
email:null
};
}
};
</script>

现在该组件已准备好供你在付款表单中使用。

受理支付

现在让我们将组件添加到表单中。 Paystack 组件有 5 个必需的 props：

  1. 金额 - 我们向客户收取的金额
  2. 邮箱 - Paystack 上的所有交易都需要客户的邮箱地址
  3. Paystack密钥 - 请记住，客户端代码的公钥始终
  4. 回调 - 成功交易完成后将运行的函数
  5. 关闭 - 当客户关闭 Paystack Checkout 时将运行的函数
<paystack
:amount="amount * 100"
:email="email"
:paystackkey="PUBLIC_KEY"
:reference="reference"
:callback="processPayment"
:close="close"
>
Make Payment
</paystack>

客户输入的金额应在提交前转换为kobo，只需将该值乘以100即可完成
