激活苹果支付

如果使用薪资画布，你可以跳过此步骤并继续下一步。

你可以在 Paystack Dashboard 上为你的 Web 应用程序配置 Apple Pay 通道。要在集成中启用 Apple Pay，请在 Paystack 仪表板上点击 转到首选项页面 并选中 Apple Pay 选项。

![图片 1：Paystack 首选项页面的图片，显示激活 Apple Pay 的复选框](https://paystack.com/docs/static/05c13462f0fdba44bf00e332fb55f493/636d3/activate_apple_pay.png)

选中后，系统将提示你接受 Apple Pay 平台网络商户条款和条件，以启用 Apple Pay。单击 Enable Apple Pay 按钮表示你已阅读并接受 Apple Pay 条款和条件。

![图片 2：激活 Apple Pay 之前查看 Apple Pay 条款和条件的模式图片](https://paystack.com/docs/static/370d4300cad1b4debc0f449e5a57e94f/e431d/review_tc.png)

如果你使用我们的 Commerce Suite（发票、付款页面或店面）或任何将用户从你的网站重定向到新付款页面的插件，你现在可以开始通过 Apple Pay 受理支付。拥有自定义 Web 应用程序的商户可以继续执行下一部分，为其网站设置 Apple Pay。

设置你的网络应用程序

每个 Apple Pay 请求都需要与顶级域或子域关联。要开始使用 Apple Pay 受理支付，你需要：

  1. 注册你的域名
  2. 托管你的域校验文件
  3. 校验你的域名

注册你的域名

根据访问的UI，步骤略有不同。

  1. 单击“设置”页面上的Apple Pay选项卡
  2. 在 Web 域部分下，单击 Add new domain 按钮 ![图片 3：Paystack Apple Pay 页面的图片，显示添加域名的位置](https://paystack.com/docs/static/45a79b8fc5a8474c8c71ba04b18d622a/a1ccc/add_domain.png)
  1. 在模式中，添加你的域名并下载域校验文件。下一步将需要校验文件。 ![图 4：显示正在注册的域名的域校验模式图像](https://paystack.com/docs/static/4117498d4464cec3d1294002728a6363/69d6b/filled_domain.png)
  1. 单击 开发者页面 上的 Apple Pay 链接
  2. 单击Add domain按钮![图片 5：Paystack Apple Pay 页面的图片，显示添加域名的位置](https://paystack.com/docs/static/406e270f3107611d4593f1650b2cb42e/e671a/apple_pay_add_domain.png)
  1. 在模式中，添加你的域名并下载域校验文件。下一步将需要校验文件。 ![图 6：显示正在注册的域名的域校验模式图像](https://paystack.com/docs/static/c7500366bdba57725f610ac389e6c3d4/03bcf/activate_apple_pay_canvas.png)

如果你想通过 API 注册你的域名，请检查 苹果支付API 接口了解更多详细信息。

托管你的域校验文件

For each top-level domain and/or subdomain registered, you need to host a verification file in the .well-known folder in your website's root directory.

例如，如果你注册了paystack.com，则校验文件应驻留在：https://paystack.com/.well-known。同样，如果你注册了music.paystack.com，则校验文件应位于：https://music.paystack.com/.well-known。

托管校验文件的过程分为两步：

  1. 在网站根目录中创建一个.well-known文件夹
  2. 将之前下载的校验文件添加到该文件夹中

![图 7：应用程序文件夹的图像，显示用于托管域校验文件的众所周知的文件夹](https://paystack.com/docs/static/d4551ff8fd571a49e50162ca7307938b/72aae/create_well_known.png)

确保返回的域校验文件的 content-type 为 application/text。使用不同的 content-type 可能会导致客户的付款失败。

校验你的域名

成功托管域名校验文件后，你可以返回Dashboard或帆布完成域名校验。

在Verify your domain模式中，单击Verify Domain按钮即可完成域名注册。如果一切顺利，你应该会收到一条经过域校验的消息，如下所示：

![图片 8：Apple Pay 域名校验成功的图片](https://paystack.com/docs/static/592c1e7cb01f3947c4256069bf1e01e3/21335/domain_verified.png)

点击Add Domain按钮完成你的域名校验。如果一切顺利，你应该会收到一条经过域校验的消息，如下所示：

![图 9：Apple Pay 域名校验成功的图片](https://paystack.com/docs/static/1095e0749d69385cecf1f4f36aa146bf/416ee/apple_pay_activated.png)

在前端应用程序中设置 Apple Pay 有两种方法：

  1. 使用结账模式
  2. 安装付款请求按钮

使用结账模式

如果你之前集成过 InlineJS 库的版本 2，则可以跳过此部分，因为 Apple Pay 将在 Paystack Checkout 的卡部分中提供。

通过这种方法，我们可以处理 Apple Pay 按钮的放置和设计。你只需将付款按钮与 checkout() 方法绑定即可：

const paystackPop = new PaystackPop();

async function payWithPaystack() {
await paystack.checkout({
key: 'pk_domain_xxxxx',
email: 'example@email.com',
amount: 10000,
onSuccess: (transaction) => {
console.log("Transaction: ", transaction)
},
onCancel: () => {
console.log("Pop up closed!")
}
});
}

如果用户使用的是 Apple 设备或 Safari 浏览器，则结账方法包括 Apple Pay 按钮，如下图所示：

![图 10：iPhone 上的预结账模式图像](https://paystack.com/docs/static/e9c279007d0fdf0be4dc301227ba6134/72aae/apple_pay_Checkout.png)

如果你集成了2.24.0以下的任何版本，用户将首先看到一个预结账模式，其中包含 Apple Pay 按钮和加载其他付款选项的按钮，如下图所示：

![图 11：iPhone 上的预结账模式图像](https://paystack.com/docs/static/04dfa1adaa240a382e655b313caad56a/25c1c/pre_Checkout.png)

安装付款请求按钮

此方法允许你根据你的设计放置 Apple Pay 按钮。这是一种灵活的方法，分为两步：

  1. 创建一个容器
  2. 设置付款请求

此过程涉及添加 HTML 标签，该标签将容纳 Apple Pay 按钮以及加载其他付款选项的按钮：

<div id="paystack-apple-pay"></div>
<button id="paystack-other-channels">More payment options</button>

你应该使用带有唯一 id 的 div 标签作为 Apple Pay 按钮的容器。上面的代码片段中使用了 paystack-apple-pay，但是，你可以使用你喜欢的任何名称。这个id将用于配置和加载Apple Pay按钮。

要配置Apple Pay按钮，你需要在paymentRequest()方法中传递容器id和其他通道的id：

const paystackPop = new PaystackPop();

await paystackPop.paymentRequest({
key: 'pk_domain_xxxxx',
email: 'CUSTOMER_EMAIL',
amount: amount * 100,
currency: 'NGN',
ref: 'YOUR_REFERENCE',
container: 'paystack-apple-pay',
loadPaystackCheckoutButton: 'paystack-other-channels',
style: {
theme: 'dark',
applePay: {
margin: '10px',
padding: '10px',
width: '100%',
borderRadius: '5px',
type: 'pay',
locale: 'en'
}
},
onSuccess(response) {

},
onError() {

},
onCancel() {

},
onElementsMount(elements) {

}
});

故障排除

如果你在 Apple Pay 集成方面遇到任何问题，请确保在设置过程中没有疏忽：

  • 你的服务端必须通过 HTTPS 服务所有请求
  • 你的仪表板上有 注册并校验你的域名
  • 你已将域校验文件托管在网站根目录的 .well-known 文件夹中
  • 如果你的服务端需要将外部服务端列入白名单才能启动通信，则你需要将 Apple 的 IP 地址列入白名单。

如果所有检查均已完成，但你的 Apple Pay 集成仍然存在问题，你可以尝试以下一些可能的错误和解决方案：

错误分辨率
Apple Pay 会话无法启动我们无法启动付款网络会话。再试一次。
不允许 Apple Pay 交易，因为商户未启用国际支付。你需要检查你的企业有资格获得国际支付。如果你的企业符合条件，按照此指南激活国际支付。
Apple Pay 交易不支持商户类别。出于合规原因，仅允许特定业务类别使用 Apple Pay。
