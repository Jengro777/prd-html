需要开始通过你的 React 应用程序受理支付？在本文中，我们将探讨如何将 Paystack 与你的 React 应用程序连接。我们将使用电子商务商店上的示例结账页面进行演示

简介

我们将在这个演示中使用我们的公钥。你可以在 PaystackDashboard 的 API 密钥和 Webhook 部分或 薪资画布 的 开发者概览 页面中找到你的 API 键。

你会注意到你有两个公钥：测试和实时。在构建应用程序时，最好使用测试密钥，因为这将允许你模拟交易。一旦你的应用程序准备好投入生产，你就可以切换到实时密钥。

由于这是客户端集成，这意味着我们的 API 密钥将被公开。为了防止任何人访问我们的 Paystack 账户，我们希望确保使用我们的 公钥。密钥只能在服务端上使用。

项目设置

那么，让我们开始编码。首先，我将创建一个新的 React 应用程序。我喜欢使用 yarn 来开始使用我的 React 应用程序，但欢迎你使用 npm 或 npx。

yarn create react-app react-paystack-checkout

创建应用程序后，我们需要导航到应用程序的目录并启动我们的应用程序：

cd react-paystack-checkout
yarn start

受理支付

我们需要做的最后一件事是将表单提交到 Paystack，这样我们就可以初始化交易。我们可以通过三种不同的方式在应用程序中使用 react-paystack 库：

  1. 薪资按钮 - 原始库实现
  2. 使用Paystack支付 - 使用 React Hooks 实现库
  3. Paystack消费者 - 使用 React 的上下文 API 的库实现

让我们为我们的应用程序使用 PaystackButton 实现：

import { PaystackButton } from 'react-paystack'

我们可以向按钮传递一些参数，但必需的参数是：

  1. 邮箱 - Paystack 上的所有交易都需要客户的邮箱地址
  2. 金额 - 我们向客户收取的金额
  3. 公钥 - 请记住，客户端代码的公钥始终
  4. 文字 - 你想要在按钮上显示的文本
  5. 成功时 - 成功交易完成后将运行的函数
  6. 关闭时 - 当客户关闭 Paystack Checkout 时将运行的函数

或者，我们可以传递交易引用和元数据对象。如果你不传递参考，Paystack 只会为你生成一个。如果你选择生成自己的引用，则需要确保 每个参考都是独一无二的。 元数据对象允许你存储交易所需的任何附加信息。在这里，我们将在元数据中传递客户的姓名和电话号码。我们将把所有这些放入一个 componentProps 对象中，并将其传递给 PaystackButton 组件。

const componentProps = {
email,
amount,
metadata: {
name,
phone,
},
publicKey,
text: "Pay Now",
onSuccess: () =>
alert("Thanks for doing business with us! Come back soon."),
onClose: () => alert("Wait! You need this oil, don't go."),
}

我们的 App.js 文件现在应该如下所示

import React, { useState } from "react"
import { PaystackButton } from "react-paystack"
import "./App.css"

const App = () => {
const publicKey = "pk_your_public_key_here"
const amount = 1000000
const [email, setEmail] = useState("")
const [name, setName] = useState("")
const [phone, setPhone] = useState("")

const componentProps = {
email,
amount,
metadata: {
name,
phone,
},
publicKey,
text: "Pay Now",
onSuccess: () =>
alert("Thanks for doing business with us! Come back soon."),
onClose: () => alert("Wait! Don't leave :("),
}

return (
<div className="App">
<div className="container">
<div className="item">
<img />
<div className="item-details">
<p>Dancing Shoes</p>
<p>{amount}</p>
</div>
</div>
<div className="checkout-form">
<form>
<label>Name</label>
<input
type="text"
id="name"
onChange={(e) => setName(e.target.value)}
/>
<label>Email</label>
<input
type="text"
id="email"
onChange={(e) => setEmail(e.target.value)}
/>
<label>Phone</label>
<input
type="text"
id="phone"
onChange={(e) => setPhone(e.target.value)}
/>
</form>
<PaystackButton {...componentProps} />
</div>
</div>
</div>
)
}

export default App
