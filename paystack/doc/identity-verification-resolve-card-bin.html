解决卡BIN

此接口获取卡 PAN 的前 6 位数字并返回有关该卡的以下详细信息：

  • 子品牌

显示回复 - [x]

curl https://api.paystack.co/decision/bin/539983
-H "Authorization: Bearer YOUR_SECRET_KEY"
-X GET
{
  "status": true,
  "message": "Bin resolved",
  "data": {
    "bin": "539983",
    "brand": "Mastercard",
    "sub_brand": "",
    "country_code": "NG",
    "country_name": "Nigeria",
    "card_type": "DEBIT",
    "bank": "Guaranty Trust Bank",
    "linked_bank_id": 9
  }
}

你可以使用此接口来确定卡的发行国家/地区。

定价

这个接口是免费的。
