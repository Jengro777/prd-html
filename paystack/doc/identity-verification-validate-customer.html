了解如何校验客户的身份详细信息

仅当你使用 专属虚拟账户 功能并且你的业务属于以下任何类别 - 博彩、金融服务和一般服务时，才需要这样做。

简介

客户校验接口用于校验客户提供的身份详细信息。你可以通过向 校验客户API 接口发送 POST 请求来校验客户。

银行账户校验

银行账户校验要求你提供客户的 BVN 以及与该 BVN 连接的银行账户。

curl https://api.paystack.co/customer/{customer_code}/identification
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{
"country": "NG",
"type": "bank_account",
"account_number": "0123456789",
"bvn": "200123456677",
"bank_code": "007",
"first_name": "Asta",
"last_name": "Lavista"
}'
-X POST
{
  "status": true,
  "message": "Customer Identification in progress"
}

测试

客户只能使用实时密钥进行校验。但是，为了在集成期间进行测试，你可以将此凭据与测试密钥一起使用：

{
  "country": "NG",
  "type": "bank_account",
  "account_number": "0111111111",
  "bvn": "222222222221",
  "bank_code": "007",
  "first_name": "Uchenna",
  "last_name": "Okoro"
}

监听校验状态

对所提供详细信息的校验是异步进行的，校验完成后，我们将向你的 Webhook URL 发送 customeridentification.success 或 customeridentification.failed 事件。

在继续本节之前，你需要了解 Webhook 的基本知识。

{
  "event": "customeridentification.success",
  "data": {
    "customer_id": "9387490384",
    "customer_code": "CUS_xnxdt6s1zg1f4nx",
    "email": "bojack@horsinaround.com",
    "identification": {
      "country": "NG",
      "type": "bank_account",
      "bvn": "200*****677",
      "account_number": "012****789",
      "bank_code": "007"
    }
  }
}

当客户校验失败时，我们会在 data.reason 参数中返回失败原因。对于客户校验失败，我们会返回以下原因：

  1. 账户无法解决。请重试
  2. 账户名或BVN不正确
  3. 帐号或BVN不正确

成功校验客户后，客户的 first_name 和 last_name 将自动更新以与其 BVN 上的姓名相对应。设置完成后，你将无法再使用 更新客户API 更新客户的姓名，并且只能通过重新校验来更新客户的姓名。

校验客户的原因

  1. 当地法规要求在代表客户创建帐号之前先校验客户信息。
  2. 它允许我们使用注册到所提供的BVN的名称来命名银行账户。
