Android SDK 测试版

Android SDK 提供 UI 组件和方法，允许你在 Android 应用程序中受理支付。

Android SDK 目前是测试版。如果你在使用过程中遇到任何问题或有建议，请随时联系我们。我们很乐意听取你的意见。

简介

Android SDK 是方法和接口的集合，允许开发人员为其 Android 应用程序构建安全、便捷的支付流程。集成过程分为两步：

  1. 在服务端上发起交易
  2. 在 SDK 上完成

项目要求

Paystack Android SDK 旨在支持 Android 6.0（API 23 级） 及以上版本。我们不支持 Android 6.0 以下的 OS 版本。在使用SDK之前，你需要确保你的应用满足以下要求：

  • Android 6.0（API 23 级）及以上
  • Android Gradle 插件 7.2 及更高版本
  • Gradle 7.1.3 及以上版本

安装

要使用 SDK，请将 paystack-ui 添加到应用程序级构建文件的dependencies块中：

安装前你应该检查梅文中心以获取最新版本。

  • 构建.gradle
dependencies {
implementation 'com.paystack.android:paystack-ui:0.0.9'
}

确保同步项目以将 SDK 下载到你的项目中。成功安装后，你将可以访问 UI 组件和方法以在 Android 应用程序中受理支付。

薪资构建器

在使用 UI 组件之前，Paystack 类使用构建器模式来处理内务管理和基础任务。它是核心库的一部分：

import com.paystack.android.core.Paystack

下表显示了 Paystack 类中可用的方法：

方法描述
setPublicKey("public-key")该方法用于设置公钥。没有公钥，你无法完成交易。
setLoggingEnabled(boolean)此方法确定你是否获得调试日志。默认情况下，它设置为false，这意味着你不会获得任何调试日志。
Paystack.builder()
.setPublicKey("pk_domain_xxxxxxxx")
.setLoggingEnabled(true)
.build()

初始化交易

SDK 需要 access_code 来显示受理支付的 UI 组件。要获取 access_code，请从服务端向 初始化交易API 接口发出 POST 请求：

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "500000"
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

交易成功初始化后，你会收到包含 access_code 的响应。你需要将此access_code返回到你的移动应用程序。

不要直接在你的移动应用程序上向初始化交易接口发出 API 请求，因为它需要你的密钥。你的密钥只能在可以采取更强安全措施的服务端上使用。

付款单

PaymentSheet 是UI 组件，包含付款表单和可用的付款渠道。它是 UI 库的一部分，可以如下所示导入：

import com.paystack.android.ui.paymentsheet.PaymentSheet

PaymentSheet类在Activity或Fragment的onCreate方法中使用两个参数进行初始化：

论据示例描述
活动this这是对你的 Activity 或 Fragment 的引用
回调paymentResult这是处理所有后支付流程的方法。它的参数的类型为 PaystackSheetResult
private lateinit var paymentSheet: PaymentSheet

override fun onCreate(savedInstanceState: Bundle?) {
super.onCreate(savedInstanceState)
setContentView(R.layout.activity_main)



paymentSheet = PaymentSheet(this, ::paymentComplete)


}

PaymentSheet 附带一个 launch 方法，允许你触发组件的显示。 launch 方法从先前初始化的交易中获取 access_code。

fun makePayment() {

paymentSheet.launch("br6cgmvflhn3qtd")
}

付款单结果

PaymentSheetResult公开了交易的不同状态。这是 PaymentSheet 回调的参数类型：

import com.paystack.android.ui.paymentsheet.PaymentSheetResult

private fun paymentComplete(paymentSheetResult: PaymentSheetResult) {

}

PaymentSheetResult暴露的不同状态是：

状态描述
已完成客户完成了支付流程。我们返回一个包含交易引用的paymentCompletionDetails。在提供价值之前，你应该使用交易参考来校验服务端上的交易状态和金额。
取消客户取消了付款。
失败付款过程中发生错误。该结果包含error。它还可能包含交易的reference。
private fun paymentComplete(paymentSheetResult: PaymentSheetResult) {
val message = when (paymentSheetResult) {
PaymentSheetResult.Cancelled -> "Cancelled"
is PaymentSheetResult.Failed -> {
Log.e("Something went wrong", paymentSheetResult.error.message.orEmpty(), paymentSheetResult.error)
paymentSheetResult.error.message ?: "Failed"
}

is PaymentSheetResult.Completed -> {

Log.d("Payment successful", paymentSheetResult.paymentCompletionDetails.toString())
"Successful"
}
}

Toast.makeText(this, "Payment $message", Toast.LENGTH_SHORT).show()
}
