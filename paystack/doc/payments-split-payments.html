通过分期付款，你可以与另一个账户共享交易结算

实施分期付款涉及：

  1. 创建子账户
  2. 初始化分期付款

创建子账户

子账户可以通过PaystackDashboard或使用创建子账户API接口创建。创建子账户时，返回subaccount_code。

curl https://api.paystack.co/subaccount
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "business_name": "Oasis",
"bank_code": "058",
"account_number": "0123456047",
"percentage_charge": 30
}'
-X POST
{
  "status": true,
  "message": "Subaccount created",
  "data": {
    "business_name": "Oasis",
    "account_number": "0123456047",
    "percentage_charge": 30,
    "settlement_bank": "Guaranty Trust Bank",
    "currency": "NGN",
    "bank": 9,
    "integration": 463433,
    "domain": "test",
    "account_name": "LARRY JAMES O",
    "product": "collection",
    "managed_by_integration": 463433,
    "subaccount_code": "ACCT_6uujpqtzmnufzkw",
    "is_verified": false,

初始化分期付款

分期付款可以通过使用初始化交易API接口并传递参数subaccount: "ACCT_xxxxxxxxxx"来初始化。

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "20000",
"subaccount": "ACCT_xxxxxxxxx"
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

分期付款可用于以下场景：

  • 服务提供商和平台提供商之间的共享支付
  • 不同账户中的单独学费，例如学费、住宿费、游览费

固定费用

默认情况下，付款按百分比分配。例如，如果使用 percentage_charge: 20 创建子账户，则 20% 分配给主账户，其余分配给子账户。

但是，你可以覆盖此默认设置并指定进入你的主账户的固定费用。为此，请在初始化交易时传递transaction_charge键。

在下面的代码片段中，主账户获得固定费用 10000，子账户获得其余费用：

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "20000",
"subaccount": "ACCT_xxxxxxxxx",
"transaction_charge": 10000
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

交易费用的承担者

默认情况下，Paystack 费用由主账户承担。要将其更改为子账户，请在初始化交易时传递参数bearer: "subaccount"。

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "20000",
"subaccount": "ACCT_xxxxxxxxx",
"bearer": "subaccount"
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

指定承载人时，你需要确保进入子账户的金额足以承担交易费用。如果金额不足，你将收到400 Bad Request错误。
