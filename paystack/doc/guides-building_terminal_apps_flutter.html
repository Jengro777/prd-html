使用 Flutter 为终端构建自定义应用程序？在本指南中，我们将探索如何使用 Flutter 的方法通道与 Paystack 应用程序交互以受理支付。

简介

Paystack Terminal 允许你构建 通过意图进行沟通 与终端应用程序一起受理支付的自定义应用程序。终端应用程序处理有关付款的所有交易，让你可以专注于构建应用程序。在付款时，你只需通过意图将付款详细信息传递给终端应用程序，系统就会处理付款并将响应传回你的应用程序。

项目设置

本指南假设你有一个现有的 Flutter 应用程序，因此，我们的重点是构建支付流程。

我们将使用 Flutter的方法通道 来允许 Dart 和 Kotlin 之间的通信。本指南是使用以下设置的指南：

  • Flutter (3.13.9)
  • 飞镖 (3.1.5)

虽然，并不强制全部按原样使用，但这会使操作更容易，并且几乎没有错误。 Android Studio 特别用于编写和管理所有Kotlin 代码。

创建模型

To get started, we’ll be creating all the models we need for the payment flow. Before creating our models, we need to 安装Gson, a library for serialising and deserialising Java/Kotlin objects.

要安装 Gson，请在 Android Studio 中打开项目中的 android 文件夹。打开后：

  1. 确保你的 Android Studio 工作区配置为 Android。
  2. 打开应用程序build.gradle。这是具有 Module: YourAppName.app 的那个。
  3. 添加 gson 作为依赖项。
  4. 弹出窗口显示到Sync Now。同步会安装依赖项并使其在你的项目中可供使用。

![图 1：Android Studio 的屏幕截图，显示依赖项安装](https://paystack.com/docs/static/60360dc482a951b326b93dfa834fbf6c/9d362/terminal_flutter_gradle.png)

安装依赖项后，我们可以创建以下模型：

data class TerminalResponse(
val statusCode: String,
val message: String,
val data: String
)

创建付款意向

模型到位后，我们现在可以创建启动付款的方法，将其传递给 Paystack 应用程序并处理结果。为此，我们需要打开 MainActivity.kt 文件。你可以在应用程序的 android → app → java → YourPackageName 中找到此文件：

![图 2：Android Studio 的屏幕截图，显示依赖项安装](https://paystack.com/docs/static/2abf712411f2fba93e405547c0ffbf5b/18936/terminal_flutter_main_activity.png)

最初，该文件包含一个空类。我们将添加发起付款和处理响应的方法：

  • MainActivity.kt
import android.content.Intent
import android.util.Log
import android.widget.Toast
import com.example.sample_registration.model.CustomField
import com.example.sample_registration.model.PaystackIntentResponse
import com.example.sample_registration.model.TerminalResponse
import com.example.sample_registration.model.TransactionRequest
import com.example.sample_registration.model.TransactionResponse
import com.google.gson.Gson
import io.flutter.embedding.android.FlutterActivity

class MainActivity: FlutterActivity() {
private val gson = Gson()
private var transactionStatus: String? = ""

private val CHANNEL = "com.example.sample_registration/payment"
private val PACKAGE_NAME = "com.paystack.pos"
private val TRANSACTION = "com.paystack.pos.TRANSACT"
private val TRANSACTION_RESULT_CODE = 14


private fun makePayment(amount: Int?) {
val transactionRequest = amount?.let {
TransactionRequest(
amount = it,
offlineReference = null,
supplementaryReceiptData = null,
metadata = mapOf(
"custom_fields" to listOf(
CustomField(
displayName = "App Name",
variableName = "app_name",
value = "Sample Registration"
)
)
)
)
}

val transactionIntent = Intent(Intent.ACTION_VIEW).apply {
setPackage(PACKAGE_NAME)
putExtra(TRANSACTION, gson.toJson(transactionRequest))
}

startActivityForResult(transactionIntent, 1)
}

override fun onActivityResult(requestCode: Int, resultCode: Int, data: Intent?) {
super.onActivityResult(requestCode, resultCode, data)
val paystackIntentResponse: PaystackIntentResponse

if (resultCode == TRANSACTION_RESULT_CODE) {
paystackIntentResponse = gson.fromJson(
data?.getStringExtra(TRANSACTION),
PaystackIntentResponse::class.java
)

processResponse(paystackIntentResponse)
}
else {

}
}

private fun processResponse(response: PaystackIntentResponse) {

val terminalResponse: TerminalResponse = response.intentResponse
val transactionResponse = gson.fromJson(
terminalResponse.data,
TransactionResponse::class.java
)

transactionStatus = transactionResponse.reference
}
}

我们在 MainActivity.kt 类中添加了三个函数：

  1. 付款：这是创建交易请求并将其交给 Paystack 应用程序的函数。这就是 transactionIntent 和 startActivityForResult 的作用。
  2. 活动结果：这是一个回调函数。当在makePayment函数中调用startActivityForResult方法时，它会自动要求该函数接收来自Paystack应用程序的响应。
  3. 过程响应：此函数基本上解析 Paystack 应用程序的结果并将其返回给Flutter。

创建方法通道

MethodChannel 在客户端（UI）和主机（平台）之间创建通信通道。在这种情况下，平台是Android。为了创建用于支付的 MethodChannel，我们将重写 configureFlutterEngine 方法并启动对 makePayment 函数的调用。我们将在 MainActivity.kt 文件中的 makePayment 函数上方添加 configureFlutterEngine 函数：

  • MainActivity.kt
import io.flutter.embedding.engine.FlutterEngine
import io.flutter.plugin.common.MethodChannel

class MainActivity: FlutterActivity() {
private val CHANNEL = "com.example.sample_registration/payment"

override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
super.configureFlutterEngine(flutterEngine)

MethodChannel(flutterEngine.dartExecutor.binaryMessenger, CHANNEL).setMethodCallHandler {
call, result ->
if (call.method == "makePayment") {
val amount = call.argument("amount") ?: 0
makePayment(amount)

result.success(transactionStatus)
} else {
result.notImplemented()
}
}
}


}

MethodChannel 基本上保留了从 Flutter 调用的函数的选项卡。如果匹配makePayment，则会触发该函数。 MainActivity.kt的完整代码已在GitHub上提供，供你参考。

你应该记下 CHANNEL 常量，因为我们将在 Flutter 代码中使用它作为标识符。

链接方法通道

现在我们回到了 Flutter 代码。我们将通过将MethodChannel链接到UI来完成MethodChannel设置。在包含付款按钮的小部件中，你需要添加一个常量来标识你要链接到的频道，并设置一个函数来调用 makePayment 函数：

  • 注册.dart
static const _methodChannel =
MethodChannel('com.example.sample_registration/payment');

Future<void> makePayment() async {
String reference = '';
try {
var options = {
'amount': 5000,
'supplementaryData': {
'developerSuppliedText': null,
'developerSuppliedImageUrlPath':
"https://assets.paystack.com/assets/img/press/Terminal-x-Bature-x-World-Cup-Receipt.jpg",
'barcodeOrQrcodeImageText': null,
'textImageType': null
}
};
reference = await _methodChannel.invokeMethod('makePayment', options);
print("Reference: $reference");
} on PlatformException catch (e) {
print("Error: $e");
reference = '';
}

setState(() {
_transactionReference = reference;
});
}

makePayment按钮可以在Button Widget的onPressed方法中调用。你现在可以测试一切是否正常。

结论

在本指南中，我们学习了如何使用 Flutter的方法通道 在 Android 和 Flutter 之间进行通信。我们能够使用这种方法将付款推送到 Paystack 应用程序。

你可以找到完整代码在Github上作为参考。
