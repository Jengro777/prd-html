多重分割使商户能够在其支付账户和一个或多个子账户之间分割交易的结算。

你可以通过以下方式实现多分割：

  1. 创建交易拆分
  2. 使用交易拆分进行付款

商户将能够使用 交易分割API 接口和 PaystackDashboard 创建和管理他们的交易拆分。

创建交易拆分

交易拆分取决于子账户来发挥其魔力。如果你已有子账户，则可以继续。否则，你需要先创建子账户。

你可以通过向 创建分割API 接口发送包含以下信息的请求来创建交易拆分：

  • 分割类型（flat或percentage）
  • 一系列子账户及其各自的份额
#!/bin/sh
url="https://api.paystack.co/split"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name":"Halfsies",
"type":"percentage",
"currency": "NGN",
"subaccounts":[{
"subaccount": "ACCT_6uujpqtzmnufzkw",
"share": 50
}]
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST

  1. 如果拆分类型为 percentage，我们不接受子账户份额的小数数字
  2. percentage 分割的总和不应超过 100%
  3. flat 分割的份额金额应位于 支持的货币 的子单位中
  4. flat分割的总和不应大于交易金额
  5. 分割可以是 flat 或 percentage 类型，但不能同时是两者

通过APIs，你可以添加、删除和更新Split中的子账户，以及更改Split的活动状态。

你无法更改拆分的类型。相反，你可以停用拆分并创建具有不同拆分类型的新拆分。

使用交易拆分进行付款

创建交易拆分后，你可以在以下情况下使用它：

  1. 初始化交易
  2. 收费授权

初始化交易

你可以通过将 split_code 添加到发送到 交易初始化API 接口的有效负载来初始化交易拆分。

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "20000",
"split_code": "SPL_98WF13Eekw"
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

动态分裂

有时，你直到购买流程后期才能确定拆分配置。通过动态拆分，你可以动态创建拆分。这可以通过将 split 对象传递给 交易初始化API 接口或弹出窗口 来实现。 split 对象可以具有以下属性：

参数需要吗？描述
type是的值可以是 flat 或 percentage
bearer_type是的值可以是 all、all-proportional、account 或 subaccount
subaccounts是的子账户对象的数组。例如{"subaccount": 'ACCT_', "share": 60}
bearer_subaccount否持有者的子账户代码。如果bearer_type是subaccount则需要指定
reference否分割的唯一参考
curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "20000",
"split": {
"type": "flat",
"bearer_type": "account",
"subaccounts": [
{
"subaccount": "ACCT_pwwualwty4nhq9d",
"share": 6000
},
{
"subaccount": "ACCT_hdl8abxl8drhrl3",
"share": 4000
},
]
}
}'
-X POST
{

多分割费用

默认情况下，主账户承担 Paystack 交易费用。但是，你可以通过将 bearer_type 设置为 account、all 或 subaccount 来更改此设置。

承载类型描述
all费用将由主账户和所有子账户平摊。
all-proportional根据主账户和子账户的份额收取费用。
account费用将仅向主账户收取。
subaccount仅对bearer_subaccount中设置的子账户进行扣费

当bearer_type设置为subaccount时，必选参数。 bearer_subaccount 的值必须是拆分组中的子账户代码。
