你可以构建自定义 Android 应用程序以在 Paystack 终端上受理支付

简介

Paystack 终端由 Android 操作系统 (OS) 提供支持，允许开发人员在终端上构建 Android 应用程序。 Android OS 使应用程序能够通过 Intent 相互通信。使用 Intents，你可以构建一个在 Paystack Terminal 上运行并受理支付的应用程序。

我们目前有两个终端设备，分别运行在 Android 5.1 和 Android 10 上。如果你要为两种设备进行构建，则应记下两个 OS 版本之间的 隐私变更。

建立意图

This document highlights how to build using the Java/Kotlin. If you are building with Flutter or React Native, check out the Flutter or React Native guide.

在为你的自定义应用程序实现支付流程时，你需要 利用意图 与 Paystack 终端应用程序进行通信。意图允许你指定应处理你的请求的特定应用程序。在这种情况下，你将指定 Paystack 终端应用程序来处理你的应用程序的付款。

在为 Paystack 终端应用程序创建意图时，你可以传递以下参数：

参数描述价值
元件名称Paystack 终端应用程序的包名称com.paystack.pos
行动捕获要执行的操作的通用字符串Intent.ACTION_VIEW
附加功能执行所需操作所需的键值对。键将包含应用程序的包名称作为前缀。例如，com.paystack.pos.SETTINGS检查下面支持的操作表

支持的操作

这些是终端上当前可用的操作：

操作额外钥匙结果代码
获取终端详细信息com.paystack.pos.PARAMETERS12
发起交易com.paystack.pos.TRANSACT14
打开终端设置com.paystack.pos.SETTINGS-

意图响应

除终端设置外，所有支持的操作都会返回具有以下结构的响应：

data class PaystackIntentResponse (
val intentKey: String,
val intentResponseCode: Int,
val intentResponse: TerminalResponse
)
参数描述
intentKey这是初始化意图时传递到 putExtra 方法的密钥。支持的操作表的 额外钥匙 列中列出了可能的值
intentResponseCode这是意图结果代码。可能的值列在 支持的操作 表的结果代码列中
intentResponse这是执行操作的响应
data class TerminalResponse(
val statusCode: String,
val message: String,
val data: String
)
参数描述
statusCode我们使用HTTP 状态码来表示响应的状态
message响应的简短摘要
data这是一个包含请求结果的序列化对象（JSON 字符串）。可以根据正在执行的操作将其反序列化为相应的对象

受理支付

要发起付款，你需要创建 TransactionRequest 对象的实例：

data class TransactionRequest(
val amount: Int,
val offlineReference: String?,
val supplementaryReceiptData: SupplementaryReceiptData?,
val metadata: Map<String, Any>?
)
参数需要吗？描述
amount是的向客户收取的金额。金额应为 kobo
offlineReference否这是发票的唯一标识符。如果你想接受先前创建的发票的付款，则可以设置此值
supplementaryReceiptData否成功付款后添加到收据的额外详细信息
metadata否附加到交易的额外数据
data class SupplementaryReceiptData(
val developerSuppliedText: String?,
val developerSuppliedImageUrlPath: String?,
val barcodeOrQrcodeImageText: String?,
val textImageType: TextImageFormat?
)
参数描述
developerSuppliedText添加到打印收据的额外文本
developerSuppliedImageUrlPath可公开访问的URL，用于将图像添加到收据中
barcodeOrQrcodeImageText用于生成条形码或QR代码的文本
textImageType指定图像文本的编码类型
enum class TextImageFormat {
QR_CODE,
AZTEC_BARCODE
}

然后 TransactionRequest 的实例作为额外的内容传递到你的意图对象中：

val gson = Gson()

private fun makePayment() {
val transactionRequest = TransactionRequest(
amount = 2000,
offlineReference = null,
supplementaryReceiptData = null,
metadata = mapOf(
"custom_fields" to listOf(
CustomField(
display_name = "Extra Detail",
variable_name = "extra_detail",
value = "1234"
)
)
)
)

val transactionIntent = Intent(Intent.ACTION_VIEW).apply {
setPackage("com.paystack.pos")
putExtra("com.paystack.pos.TRANSACT", gson.toJson(transactionRequest))
}


startActivityForResult.launch(transactionIntent)
}

使用开始活动获取结果合约，结果可以解析如下：

val TRANSACTION_RESULT_CODE = 14
val TRANSACTION = "com.paystack.pos.TRANSACT"
val startActivityForResult: ActivityResultLauncher<Intent> = registerForActivityResult(StartActivityForResult(), intentResultCallback())

private fun intentResultCallback(): ActivityResultCallback<ActivityResult> {

return ActivityResultCallback { result: ActivityResult ->
val resultCode = result.resultCode
val intent = result.data
val paystackIntentResponse: PaystackIntentResponse
val terminalResponse: TerminalResponse

if (resultCode == TRANSACTION_RESULT_CODE) {
paystackIntentResponse = gson.fromJson(
intent?.getStringExtra(TRANSACTION),
PaystackIntentResponse::class.java
)
terminalResponse = paystackIntentResponse.intentResponse
val transactionResponse: TransactionResponse = gson.fromJson(
terminalResponse.data,
TransactionResponse::class.java
)

Toast.makeText(
applicationContext,
"Transaction ref: " + transactionResponse.reference,
Toast.LENGTH_SHORT
).show()
}
else {

}
}
}

支付完成后，返回的响应是TransactionResponse对象的实例：

获取终端详细信息

每个终端都有一个唯一的标识符和序列号。要获取这些详细信息，你可以构造一个意图，如下所示：

private fun fetchParameters(){
val parametersIntent = Intent(Intent.ACTION_VIEW).apply {
setPackage("com.paystack.pos")
putExtra("com.paystack.pos.PARAMETERS", "true")
}


startActivityForResult.launch(parametersIntent)
}

使用StartActivityForResult合约，结果可以解析如下：

val PARAMETERS_RESULT_CODE = 12
val PARAMETERS = "com.paystack.pos.PARAMETERS"
val startActivityForResult: ActivityResultLauncher<Intent> = registerForActivityResult(StartActivityForResult(), intentResultCallback())

private fun intentResultCallback(): ActivityResultCallback<ActivityResult> {

return ActivityResultCallback { result: ActivityResult ->
val resultCode = result.resultCode
val intent = result.data
val paystackIntentResponse: PaystackIntentResponse
val terminalResponse: TerminalResponse

if (resultCode == PARAMETERS_RESULT_CODE) {
paystackIntentResponse = gson.fromJson(
intent?.getStringExtra(PARAMETERS),
PaystackIntentResponse::class.java
)
terminalResponse = paystackIntentResponse.intentResponse
val parameters: ParameterResponse = gson.fromJson(
terminalResponse.data,
ParameterResponse::class.java
)
Toast.makeText(
applicationContext,
"Terminal ID: " + parameters.terminalId,
Toast.LENGTH_SHORT
).show()

Toast.makeText(
applicationContext,
"Terminal Serial Number: " + parameters.serialNumber,
Toast.LENGTH_SHORT
).show()
}
else {

}
}
}

结果是 PaystackIntentResponse 类的实例。解析结果可以访问终端详细信息，它是 ParametersResponse 类的实例：

import com.google.gson.annotations.SerializedName

data class ParametersResponse(
@SerializedName("terminal_id")
val terminalId: String,
@SerializedName("serial_number")
val serialNumber: String
)

打开终端设置

终端设置活动允许你执行管理操作。你可以通过在 Intent 中传递 com.paystack.pos.SETTINGS extra，以编程方式从你的应用程序打开终端应用程序的设置页面。此操作不会返回结果，因此你将使用 startActivity 方法来触发意图：

private fun openSettings() {
val settingsIntent = Intent(Intent.ACTION_VIEW).apply {
setPackage("com.paystack.pos")
putExtra("com.paystack.pos.SETTINGS", "true")
}

startActivity(settingsIntent)
}

集成清单

  • 确保你的应用程序上有HTTPS 已启用
  • Android OS 对一个应用程序可以发送到另一个应用程序的有效负载大小进行了限制。你应该 检查限制 并确保不超过它。

发布你的应用程序

完成应用程序的开发和测试后，你希望使其在所有终端设备上可用。我们管理一个应用程序商店，允许我们将你的应用程序仅提供给你的设备。将应用程序部署到所有设备上需要执行四个步骤：

  1. 生成你的应用程序APK
  2. 表示有兴趣部署自定义应用程序通过此表格，我们将向你发送详细的部署指南
  3. 按照上述步骤 2 完成初步扫描
  4. 将你的 APK 发送给我们

当我们收到你提交的内容时，我们将进行安全审查，以确保该应用程序可供公众安全使用。一旦应用程序被认证为安全，我们会将你的应用程序部署到你的所有终端。但是，如果应用程序未通过安全审核，我们将共享包含修复反馈的文档。
