受理一笔支付

下面是使用 Paystack API 受理支付的示例流程。

开始之前

调用 Paystack API 时，需使用你的私钥（Secret Key）完成鉴权。

POSTapi.paystack.co/transaction/initializecURL
curl https://api.paystack.co/transaction/initialize \
  -H "Authorization: Bearer YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -X POST

查看「初始化交易」接口参数 →
