在本指南中，我们将介绍如何迁移到 Popup V2，以便你在应用程序中受理支付时可以开始利用更精细的控制。

有什么新消息

Popup V2 包含多种功能，可帮助开发人员安全地定制并更好地控制其前端应用程序的支付。 Popup V2 上提供的一些闪亮新功能包括：

  • 从 API 发起交易并用 Popup 完成交易
  • 还有更多...

更新依赖

你可以根据你的工作流程和偏好安装Popup V2：

<script src="https://js.paystack.co/v2/inline.js">

如果你使用 NPM 或 Yarn，请确保导入该库：

import PaystackPop from '@paystack/inline-js';

更新方法

在 Popup V1 和 V2 上初始化交易时存在细微差别。为了确保平稳过渡，我们将突出显示差异并向你展示如何更新必要的方法和参数。

初始化

对于Popup V1，交易使用PaystackPop.setup()方法初始化。然后通过调用 openIframe() 方法来触发 Popup：

let paystack = PaystackPop.setup({
key: 'pk_domain_xxxxxxxxxx',
email: 'example@email.com',
amount: 10000
});

paystack.openIframe();

Popup V2 提供了更直观的界面，如下图：

const paystack = new PaystackPop();
paystack.newTransaction({
key: 'pk_domain_xxxxxxxxxx',
email: 'example@email.com',
amount: 10000
});

回调

回调用于获取付款状态。我们替换了一些回调方法，并在 Popup v2 中引入了新方法。

  • 版本1
let paystack = PaystackPop.setup({

callback: function(transaction){

},
onClose: function(){

}
});

paystack.openIframe();
  • 版本2
const paystack = new PaystackPop();
paystack.newTransaction({


onSuccess: (transaction) => {

},
onCancel: () => {

}
});

指示交易成功的callback()方法现已替换为onSuccess()回调。 onClose() 方法可让你知道用户何时关闭 Popup，现已替换为 onCancel()。

另请注意，V2 允许你使用箭头函数。哎呀，保留额外的击键来做其他事情吧。

后续步骤

我们去直播吧。测试你的集成以确保其按预期工作并删除所有冗余代码。你可以查看 InlineJS 参考指南 了解 Popup V2 中提供的其他强大功能。快乐编码。
