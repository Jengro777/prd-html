iOS SDK 测试版

iOS SDK 提供 UI 组件和方法，允许你在 iOS 应用程序中受理支付。

iOS SDK 目前是测试版。如果你在使用过程中遇到任何问题或有建议，请随时联系我们。我们很乐意听取你的意见。

简介

iOS SDK 是方法和接口的集合，允许开发人员为其 iOS 应用程序构建安全、便捷的支付流程。集成过程分为两步：

  1. 在服务端上发起交易
  2. 在 SDK 上完成

项目要求

Paystack iOS SDK 旨在支持 iOS 13 及以上版本。我们不支持iOS 13以下的OS版本。在使用SDK之前，你需要确保你的应用满足以下要求：

  • iOS 13 及以上

安装

iOS SDK 附带两个套件：

  1. Paystack核心：包含APIs和处理付款的方法。
  2. Paystack界面：包含UI组件，用于收集客户的支付信息并显示支付状态。

你可以通过 Swift 包管理器 安装这些软件包。要添加所需的软件包，请确保已安装 最新版本的 XCode 并按照以下步骤操作：

  1. 选择文件 > 添加包依赖项...
  2. 在包依赖搜索框中复制存储库 URL 并粘贴它

你可以阅读 Swift 包管理器文档 了解有关向项目添加包的更多信息。

支付堆栈核心

在使用 UI 组件之前，PaystackCore 模块使用构建器模式来处理内务管理和基础任务。

import PaystackCore

下表显示了 Paystack 类中可用的方法：

方法描述
setKey("public-key")该方法用于设置公钥。没有公钥，你无法完成交易。
enableLogging()此方法确定你是否获得调试日志。默认情况下，日志记录处于禁用状态。添加此方法可以启用日志记录。
let paystack = try? PaystackBuilder
.newInstance
.setKey("pk_domain_xxxxxxxx")
.build()

初始化交易

SDK 需要 access_code 来显示受理支付的 UI 组件。要获取 access_code，请从服务端向 初始化交易API 接口发出 POST 请求：

curl https://api.paystack.co/transaction/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "500000"
}'
-X POST
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/nkdks46nymizns7",
    "access_code": "nkdks46nymizns7",
    "reference": "nms6uvr1pl"
  }
}

交易成功初始化后，你会收到包含 access_code 的响应。你需要将此access_code返回到你的移动应用程序。

不要直接在你的移动应用程序上向初始化交易接口发出 API 请求，因为它需要你的密钥。你的密钥只能在可以采取更强安全措施的服务端上使用。

PaystackUI

PaymentUI 模块包含管理支付表单和可用支付渠道的 UI 组件。你可以将此模块添加到你的项目中，如下所示：

import PaystackUI

PaystackUI模块有两种方法：

  1. chargeUIButton：这最适合 SwiftUI。
  2. presentChargeUI：这最适合 UIKit。

充电UI按钮

我们提供了一个按钮，你可以自定义该按钮来触发付款UI。该方法采用以下参数：

参数类型描述
accessCode字符串这是在初始化交易后从你的服务端获取的。
onComplete回调此方法处理所有后支付流程。它的参数的类型为TransactionResult。
paystack?.chargeUIButton(accessCode: "0peioxfhpn", onComplete: paymentDone) {
Text("Initiate Payment")
}

当前收费UI

使用此方法，你需要创建一个按钮来触发付款UI的显示。 Payment UI 需要一个要挂钩的视图，因此你需要提供对正在显示的视图的视图控制器的引用，以及下表中列出的其他参数：

参数类型描述
on视图控制器当前视图的视图控制器。
accessCode字符串这是在初始化交易后从你的服务端获取的。
onComplete回调此方法处理所有后支付流程。它的参数的类型为TransactionResult。
@IBAction func payButtonTapped(_ sender: Any) {
paystack?.presentChargeUI(on: self,
accessCode: "0peioxfhpn",
onComplete: paymentDone)
}

交易结果

TransactionResult公开了交易的不同状态。这是 PaystackUIonComplete 回调的参数类型：

状态描述
已完成客户完成了支付流程。我们返回一个包含交易引用的paymentCompletionDetails。在提供价值之前，你应该使用交易参考来校验服务端上的交易状态和金额。
取消客户取消了付款。
失败付款过程中发生错误。该结果包含ChargeError。 ChargeError包含cause属性，详细说明了收到的实际错误，应用于错误处理和日志记录
func paymentDone(_ result: TransactionResult) {
switch (result){
case .completed(let details):
print("Transaction completed with reference: (details.reference)")
case .cancelled:
print("Transaction was cancelled")
case .error(error: let error, reference: let reference):
print("An error occured: (error.message) with reference: (String(describing: reference))")
}
}
