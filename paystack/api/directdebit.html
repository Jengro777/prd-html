API 参考

直接借记

直接借记 API 用于管理客户银行账户上的支付授权。

触发激活扣款

PUT /directdebit/activation-charge

代客户对待处理的授权委托发起激活扣款

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customer_idsarray必填

处于待处理授权委托状态的客户 ID 数组。

请求示例cURL
#!/bin/sh
curl https://api.paystack.co/directdebit/activation-charge
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ 
"customer_ids": [28958104, 983697220]
}'
-X PUT
响应示例JSON
Ok
{
"status": true,
"message": "Mandate is queued for retry"
}

查询授权委托列表

GET /directdebit/mandate-authorizations

获取集成中的直接借记授权委托列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

cursorString必填

要获取的下一组支付授权的游标值，可从响应的 meta 对象中获取

statusString必填

按支付授权状态筛选，可选值：pending，active，revoked

per_pageInteger必填

每次请求获取的支付授权数量

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/directdebit/mandate-authorizations"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
