API 参考

Capitec Pay

Capitec Pay API 用于为使用 Capitec 银行 App 的客户处理安全支付。

Capitec Pay 目前仅面向南非企业开放。

重新查询交易

POST /capitec-pay/requery/{ref}

查询使用 Capitec Pay 发起的扣款状态。该接口需要从前端应用调用，因为请求鉴权需要使用你的公钥。

请求头（Headers）

authorizationString必填

取值设为 Bearer PUBLIC_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

refString必填

此前发起扣款请求时的交易 reference

建议在 90 秒后再开始轮询结果，且轮询间隔不少于 10 秒；间隔小于 10 秒会返回缓存数据。
请求示例cURL
#!/bin/sh
url="https://api.paystack.co/capitec-pay/requery/{ref}"
authorization="Authorization: Bearer pk_domain_xxxxx"

curl "$url" -H "$authorization" -X GET
响应示例JSON
Ok
{
"status": true,
"type": "success",
"code": "ok",
"data": {
"status": "success"
},
"message": "Charge successful"
}
