API 参考

店铺

店铺 API 用于创建和管理展示、销售商品的数字店铺。

创建店铺

POST /storefront

创建数字店铺，用于管理和展示你的商品

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

nameString必填

店铺名称

slugString可选

店铺的 URL Slug，必须唯一

descriptionString可选

店铺的描述

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/storefront"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "My Storefront",
"slug": "my-storefront",
"description": "A description of my storefront"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Storefront created",
  "data": {
    "id": 1559046,
    "name": "My Storefront",
    "slug": "my-storefront",
    "description": "A description of my storefront",
    "status": "inactive",
    "currency": "NGN",
    "createdAt": "2024-11-01T12:00:00.000Z",
    "updatedAt": "2024-11-01T12:00:00.000Z"
  }
}

查询店铺列表

GET /storefront

查询集成中的店铺列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger可选

指定每页返回的记录数，未指定时默认 50。

pageInteger可选

指定要查看的页码，未指定时默认 1。

statusString可选

按店铺状态筛选，取值为 active或 inactive

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/storefront"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
响应示例JSON
{
  "status": true,
  "message": "Storefronts retrieved",
  "data": [
    {
      "id": 1559046,
      "name": "My Storefront",
      "slug": "my-storefront",
      "description": "A description of my storefront",
      "status": "active",
      "currency": "NGN",
      "createdAt": "2024-11-01T12:00:00.000Z",
      "updatedAt": "2024-11-01T12:00:00.000Z"
    }
  ],
  "meta": {
    "total": 1,
    "skipped": 0,
    "perPage": 50,
    "page": 1,
    "pageCount": 1
  }
}

向店铺添加商品

POST /storefront/:id/product

将已创建的商品添加到店铺

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

idInteger必填

店铺 ID

请求体参数（Body Parameters）

productsArray必填

要添加到店铺的商品 ID 数组

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/storefront/1559046/product"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"products": [2196244, 2196245]
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Products added to storefront"
}
