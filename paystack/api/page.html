支付页面

支付页面 API 提供了一种快捷、安全地收取商品款项的方式。

创建支付页面

POST /page

在你的集成中创建支付页面

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

nameString必填

支付页面名称

descriptionString可选

支付页面的描述

amountInteger可选

金额应使用 支持的货币的最小单位

currencyString可选

交易币种，默认使用你集成的结算货币。

slugString可选

要与该页面关联的 URL Slug，页面访问地址为 https://paystack.com/pay/[slug]

typeString可选

要创建的支付页面类型，可选值：payment，subscription，product，以及 plan。默认值为 payment（未指定类型时使用）。

planString可选

该支付页面上客户订阅的计划 ID，触发条件：type被设为 subscription。

fixed_amountBoolean可选

指定支付页面是否只收取固定金额。若为 true，则 amount必须传入。

split_codeString可选

分账的代码，例如 SPL_98WF13Eb3w

metadataObject可选

用于配置支付页面的附加数据，包括子账户、Logo 图片、交易手续费承担方

redirect_urlString可选

如果希望 Paystack 在支付成功后跳转到指定地址，请在此填写 URL。

success_messageString可选

交易成功后展示给客户的成功提示语

notification_emailString可选

接收该支付页面交易通知的邮箱地址

collect_phoneBoolean可选

指定支付页面是否收集手机号

custom_fieldsArray可选

如果需要收集自定义字段，请在此指定。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/page"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "Buttercup Brunch",
"amount": 500000,
"description": "Gather your friends for the ritual that is brunch",
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Page created",
  "data": {
    "name": "Onipan and Hassan",
    "description": "",
    "amount": 10000,
    "split_code": "SPL_yqSS1FvrBz",
    "integration": 463433,
    "domain": "test",
    "slug": "1got2y8unp",
    "currency": "NGN",
    "type": "payment",
    "collect_phone": false,
    "active": true,
    "published": true,

  }

查询支付页面列表

GET /page

查询集成中的支付页面列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

fromDatetime可选

开始列出支付页面的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出支付页面的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/page"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

更新支付页面

PUT /page/:id_or_slug

更新集成中支付页面的信息

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

id_or_slugString必填

支付页面 ID 或 Slug

请求体参数（Body Parameters）

nameString必填

支付页面名称

descriptionString必填

支付页面的描述

amountInteger可选

该页面的默认收款金额。若未设置，客户可自行填写任意金额，适用于接受捐赠等场景

activeBoolean可选

设为 false 可停用页面链接

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/page/:id_or_slug"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "Buttercup Brunch",
"amount": 500000
"description": "Gather your friends for the ritual that is brunch",
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X PUT
响应示例JSON
{
