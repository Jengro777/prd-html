预授权

预授权 API 让南非商户可以先在客户账户上冻结一笔金额，稍后再扣款。

初始化预授权

POST /preauthorization/initialize

为新客户初始化预授权交易

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

amountString必填

金额应使用 支持的货币的最小单位

emailString必填

客户的邮箱地址

currencyString必填

仅 ZAR目前支持

referenceString可选

唯一的交易 reference。仅允许 -，.，=以及字母数字字符。

callback_urlString可选

完整 URL，例如 https://example.com/ 。用它覆盖 Dashboard 上为该交易配置的回调地址

metadataString可选

自定义数据的 JSON 字符串，请参见 Metadata 元数据页面了解更多。

split_codeString可选

分账的代码，例如 SPL_98WF13Eb3w

splitObject可选

动态分账对象

transaction_chargeInteger可选

用于覆盖单笔分账配置的金额。设置后，该金额将全额进入主账户，不受分账配置影响。

bearerString可选

指定由谁承担本笔交易的 Paystack 手续费。取值为 account或 subaccount（默认取 account）。

expire_actionString可选

指定到期日执行的操作，取值为 capture或 release。默认值为 release。

expire_after_daysInteger可选

距以下时间的剩余天数：expire_action执行之前的天数。最少 1 天，默认 5 天。

请求示例cURL
curl https://api.paystack.co/preauthorization/initialize
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{ "email": "customer@email.com",
"amount": "500000",
"currency": "ZAR"
}'
-X POST
响应示例JSON
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/preauthorization/NDEyOTIyOmxpdmU6ZWloZ2VodTNyczZjanJj",
    "access_code": "NDEyOTIyOmxpdmU6ZWloZ2VodTNyczZjanJj",
    "reference": "eihgehu3rs6cjrc"
  }
}

取值设为 application/json

-H "Authorization: Bearer YOUR_SECRET_KEY"

-d '{
"reference": "123-abc"
}'
-X POST

"message": "Successfully released",

"status": "released",
"reference": "123-abc"
}

查询预授权列表

GET /transaction

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

customerInteger可选

用于查询该客户交易的唯一客户 ID

statusString可选

按状态筛选交易，取值为 authorized，captured，released，ongoing，failed，abandoned

fromDatetime可选

开始列出交易的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出交易的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

amountInteger可选

按金额筛选交易，使用 支持的货币的最小单位代码
