虚拟终端

虚拟终端 API 让你无需 POS 设备也能受理线下支付。

创建虚拟终端

POST /virtual_terminal

为你的集成创建虚拟终端

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

nameString必填

虚拟终端名称

destinationsArray必填

对象数组，表示虚拟终端收款的接收通知方。每个对象包含 target参数，用于指定接收通知的 WhatsApp 手机号，以及 name参数，用于设置描述性标签。

metadataArray必填

自定义数据的 JSON 字符串，更多说明请参见 Metadata 页面

currencyArray必填

虚拟终端的交易币种，默认使用你集成的结算货币

custom_fieldsArray必填

对象数组，表示表单上展示的自定义字段。每个对象包含 display_name参数，表示虚拟终端页面展示的内容，以及 variable_name参数，用于在代码中引用该自定义字段

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/virtual_terminal"
authorization="Authorization: Bearer SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "Sample Terminal",
"destinations": [
{
"target": "+27639022319",
"name": "Phone Destination"
}
]
}'

curl "$url" -H "$authorization" -H "$content_type" -X POST -d "$data"
响应示例JSON
{
  "status": true,
  "message": "Virtual Terminal created",
  "data": {
    "id": 27691,
    "name": "Sample Terminal",
    "integration": 530700,
    "domain": "test",
    "code": "VT_LJK5892Z",
    "paymentMethods": [],
    "active": true,
    "metadata": null,
    "destinations": [
      {
        "target": "+27639022319",
        "type": "whatsapp",
        "name": "Phone Destination"
      }
    ],
    "currency": "ZAR"
  }
}

取消虚拟终端收款账户

POST /virtual_terminal/:code/destination/unassign

取消虚拟终端与某个收款目标（WhatsApp 号码）的关联

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

codeString必填

虚拟终端代码

请求体参数（Body Parameters）

targetsArray必填

要取消关联的收款目标数组

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/virtual_terminal/:code/destination/unassign"
authorization="Authorization: Bearer SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"targets": ["+2348123456789"]
}'
curl "$url" -H "$authorization" -H "$content_type" -X POST -d "$data"
响应示例JSON
{
  "status": true,
  "message": "Destination deleted successfully"
}
