交易

交易 API 用于在你的集成中创建和管理支付。

初始化交易

POST /transaction/initialize

从后端初始化一笔交易

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

amountString必填

金额应使用 支持的货币的最小单位

emailString必填

客户的邮箱地址

channelsArray可选

支付渠道数组，用于控制结账页面向用户开放的渠道。可选渠道包括：["card", "bank", "apple_pay", "ussd", "qr", "mobile_money", "bank_transfer", "eft", "capitec_pay", "payattitude"]

currencyString可选

交易的 结算货币。默认使用你集成的结算货币。

referenceString可选

唯一的交易 reference。仅允许 -，.，=以及字母数字字符。

callback_urlString可选

完整 URL，例如 https://example.com/ 。用它覆盖 Dashboard 上为该交易配置的回调地址

planString可选

如果该交易要为预设订阅计划创建订阅，请在此提供计划代码，这将使 amount

invoice_limitInteger可选

订阅该计划期间向客户扣款的次数

metadataString可选

自定义数据的 JSON 字符串，参见 Metadata 元数据页面了解更多。

split_codeString可选

分账的代码，例如 SPL_98WF13Eb3w

subaccountString可选

拥有该笔款项的子账户代码，例如 ACCT_8f4s1eq7ml6rlzj

transaction_chargeInteger可选

用于覆盖单笔分账配置的金额。设置后，该金额将全额进入主账户，不受分账配置影响。

bearerString可选

使用该参数指定由谁承担交易手续费，可选值：account或 subaccount（默认取 account）。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/transaction/initialize"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"email": "customer@email.com",
"amount": "20000"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Authorization URL created",
  "data": {
    "authorization_url": "https://checkout.paystack.com/3ni8kdavz62431k",
    "access_code": "3ni8kdavz62431k",
    "reference": "re4lyvq3s3"
  }
}

查询交易列表

GET /transaction

查询集成中的交易列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

customerInteger可选

指定要查询交易所属客户的 ID

terminalidString可选

要查询交易所属的终端 ID

statusString可选

按状态筛选交易（'failed'、'success'、'abandoned'）

fromDatetime可选

开始列出交易的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出交易的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

amountInteger可选

按金额筛选交易，使用 支持的货币的最小单位代码

如果你计划存储或使用交易 ID，请将其表示为无符号 64 位整数。了解更多请查看变更日志。

查询交易

GET /transaction/:id

查询集成中某笔交易的详情

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

idInteger必填

要查询的交易 ID

如果你计划存储或使用交易 ID，请将其表示为无符号 64 位整数。了解更多请查看变更日志。
所有标记为可复用的支付授权，都可以在你需要收款时通过该接口发起扣款
自定义数据的 JSON 字符串。更多说明请参考 Metadata 页面。
对本笔交易向子账户收取的固定费用，使用[支持的货币]的最小单位。该值会覆盖创建子账户时设置的分成比例。如果你按固定金额分账，就需要使用该参数（创建子账户时只支持按比例分账）。
如果进行定时扣款调用，建议将其排队处理，避免处理系统过载导致交易处理错误。传入 queue:true 即可使用排队扣款能力。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

amountString必填

金额应使用 支持的货币的最小单位

emailString必填

客户的邮箱地址

authorization_codeString必填

用于扣款的有效支付授权码

referenceString可选

唯一的交易 reference。仅允许 -，.，=以及字母数字字符。

currencyString可选

货币（其中需要指定扣款金额）。

metadataString可选

自定义数据的 JSON 字符串，参见 Metadata 元数据页面了解更多。

channelsArray可选

传入 'card'、'bank' 或数组形式的 'card','bank'，用于指定向付款用户展示的选项

subaccountString可选

拥有该笔款项的子账户代码，例如 ACCT_8f4s1eq7ml6rlzj

transaction_chargeInteger可选

对本笔交易向子账户收取的固定费用，使用支持的货币的最小单位。该值会覆盖创建子账户时设置的分成比例。若按固定金额分账，需要使用该参数（创建子账户时仅支持按比例分账）。

bearerString可选

由谁承担 Paystack 手续费？ account或 subaccount（默认取 account）。

queueBoolean可选

如果进行定时扣款调用，建议将其排队，避免处理系统过载导致交易处理错误。传入 queue:true即可使用排队扣款能力。
