结算

结算 API 用于查看 Paystack 向你银行账户付款的明细。

查询结算列表

GET /settlement

查询已结算到结算账户的记录列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

statusString可选

按状态筛选结算记录，取值为 success，processing，pending或 failed。

subaccountString可选

传入子账户 ID 时仅导出该子账户的结算记录。设为 none（仅导出该账户的交易）。

fromDatetime可选

开始列出结算记录的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出结算记录的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/settlement"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET

查询结算交易列表

GET /settlement/:id/transactions

获取构成某次结算的交易明细

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

idString必填

要查询交易明细的结算 ID

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

fromDatetime可选

开始列出结算交易的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出结算交易的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

如果你计划存储或使用交易 ID，请将其表示为无符号 64 位整数。了解更多请查看变更日志。
请求示例cURL
#!/bin/sh
url="https://api.paystack.co/settlement/:id/transactions"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
