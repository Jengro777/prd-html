转账收款人

转账收款人 API 用于创建和管理你的转账对象（收款人）。

创建转账收款人

POST /transferrecipient

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

typeString必填

收款人类型，可选值：nuban，ghipss，mobile_money或 basa

nameString必填

收款人账户登记的名称。

account_numberString必填

除以下类型外，所有收款人类型均为必填：authorization

bank_codeString必填

除以下类型外，所有收款人类型均为必填：authorization。你可以调用 查询银行列表接口。

descriptionString可选

收款人的描述

currencyString可选

接收转账账户的币种

authorization_codeString可选

来自此前交易的支付授权码

metadataObject可选

以结构化格式（JSON）存储收款人的附加信息

批量创建转账收款人

POST /transferrecipient/bulk

批量创建转账收款人。若账号重复，将返回已有记录。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

batchArray必填

转账收款人对象列表，每个对象应包含 type，name，以及 bank_code。可为 创建转账收款人参数也可以传入。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/transferrecipient/bulk"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"batch": [
{
"type":"nuban",
"name" : "Habenero Mundane",
"account_number": "0123456789",
"bank_code": "033",
"currency": "NGN"
},
{
"type":"nuban",
"name" : "Soft Merry",
"account_number": "98765432310",
"bank_code": "50211",
"currency": "NGN"
}]
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST

查询转账收款人列表

GET /transferrecipient

查询集成中的转账收款人列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

fromDatetime可选

开始列出转账收款人的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出转账收款人的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/transferrecipient"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET

更新转账收款人

PUT /transferrecipient/:id_or_code

更新集成中的转账收款人

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

id_or_codeString必填

转账收款人的 ID 或代码

请求体参数（Body Parameters）

nameString必填

收款人名称

emailString可选

收款人的邮箱地址

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/transferrecipient/{id_or_code}"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "Rick Sanchez"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X PUT

删除转账收款人

DELETE /transferrecipient/:id_or_code

删除转账收款人（将收款人置为停用状态）

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

id_or_codeString必填

要删除的收款人 ID 或代码。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/transferrecipient/{id_or_code}"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X DELETE
响应示例JSON
{
  "status": true,
  "message": "Transfer recipient set as inactive"
}
