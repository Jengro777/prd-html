订阅

订阅 API 用于在集成中创建和管理周期扣款。

创建订阅

POST /subscription

在你的集成中创建订阅

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customerString必填

客户的邮箱地址或客户代码

planString必填

订阅计划代码

authorizationString必填

如果客户有多个支付授权，可在此指定该订阅使用的授权；若不传，将使用客户最近一次的支付授权

start_dateString可选

设置首次扣款日期（ISO 8601 格式），例如 2017-05-16T00:30:13+01:00

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/subscription"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"customer": "CUS_xnxdt6s1zg1f4nx",
"plan": "PLN_gx2wn530m0i3w3m"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST

查询订阅列表

GET /subscription

查询集成中的订阅列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

customerInteger可选

按客户 ID 筛选

planInteger可选

按订阅计划 ID 筛选

#!/bin/sh
url="https://api.paystack.co/subscription"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

启用订阅

POST /subscription/enable

启用集成中的订阅

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

codeString必填

订阅代码

tokenString必填

邮箱令牌

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/subscription/enable"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"code": "SUB_vsyqdmlzble3uii",
"token": "d7gofp6yppn3qz7"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Subscription enabled successfully"
}
