专属虚拟账户

专属虚拟账户 API 让尼日利亚和加纳商户可以为客户管理专属收款账户。

创建专属虚拟账户

POST /dedicated_account

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customerString必填

客户 ID 或代码

preferred_bankString可选

首选银行的 bank slug。要获取可用银行列表，请调用 查询服务商列表接口。

subaccountString可选

参与本次交易分账的子账户代码

split_codeString可选

分账代码，包含参与本次交易分账的账户列表

first_nameString可选

客户的名

last_nameString可选

客户的姓

phoneString可选

客户的手机号

分配专属虚拟账户

POST /dedicated_account/assign

使用该接口可以创建客户、校验客户，并为该客户分配专属虚拟账户。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

emailString必填

客户邮箱地址

first_nameString必填

客户的名

last_nameString必填

客户的姓

phoneString必填

客户的手机号

preferred_bankString必填

首选银行的 bank slug。要获取可用银行列表，请调用 查询服务商列表接口。

countryString必填

目前支持 NG和 GH仅

account_numberString可选

客户的银行账号

bvnString可选

客户的银行验证号（仅尼日利亚）

bank_codeString可选

客户的银行代码

subaccountString可选

参与本次交易分账的子账户代码

split_codeString可选

分账代码，包含参与本次交易分账的账户列表

你可以调用[查询银行服务商]接口获取支持的银行。
请求示例cURL
#!/bin/sh
url="https://api.paystack.co/dedicated_account/assign"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"email": "janedoe@test.com",
"first_name": "Jane",
"middle_name": "Karen",
"last_name": "Doe",
"phone": "+2348100000000",
"preferred_bank": "test-bank",
"country": "NG"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Assign dedicated account in progress"
}

重新查询专属虚拟账户

GET /dedicated_account/requery/:account_number

重新查询专属虚拟账户以获取最新交易

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

account_numberString必填

要重新查询的虚拟账户号码

provider_slugString必填

银行的小写 slug（不含空格），例如 wema-bank

dateString可选

转账发生的日期，格式 YYYY-MM-DD格式

请求示例cURL
#!/bin/sh
accountNumber="1234567890"
providerSlug="example-provider"
date="2023-05-30"

url="https://api.paystack.co/dedicated_account/requery?account_number=$accountNumber&provider_slug=$providerSlug&date=$date"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"

curl "$url" -H "$authorization" -H "$content_type" -X GET
响应示例JSON
{
  "status": true,
  "message": "We are checking the status of your transfer. We will send you a notification once it is confirmed"
}

移除专属虚拟账户的分账

DEL /dedicated_account/split

如果你此前为专属虚拟账户的交易配置了分账，可通过该接口移除

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

account_numberString必填

专属虚拟账户号码

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/dedicated_account/split"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"account_number": "0033322211"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X DELETE
响应示例JSON
{

  "message": "Subaccount unassigned",
  "data": {
    "id": 22173,
    "split_config": {},

    "assigned": true,
