客户

客户 API 用于在你的集成中创建和管理客户。

创建客户

POST /customer

在你的集成中创建客户

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

emailString必填

客户的邮箱地址

first_nameString必填

客户的名

last_nameString必填

客户的姓

phoneString可选

客户的手机号

metadataObject可选

可附加到客户的一组键值对，用于以结构化方式存储附加信息。

first_name、last_name 和 phone 是可选参数。但如果创建的客户需要分配专属虚拟账户，且你的业务类型属于 Betting、Financial services 或 General Service，则这些参数为必填。
请求示例cURL
#!/bin/sh
url="https://api.paystack.co/customer"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"email": "customer@example.com",
"first_name": "Zero",
"last_name": "Sum",
"phone": "+2348123456789"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Customer created",
  "data": {
    "email": "customer@email.com",
    "integration": 100032,
    "domain": "test",
    "customer_code": "CUS_xnxdt6s1zg1f4nx",
    "id": 1173,
    "identified": false,
    "identifications": null,
    "createdAt": "2016-03-29T20:03:09.584Z",
    "updatedAt": "2016-03-29T20:03:09.584Z"
  }
}

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

校验客户

POST /customer/:code/identification

校验客户身份

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

codeString必填

待校验客户的邮箱或客户代码

请求体参数（Body Parameters）

first_nameString必填

客户的名

middle_nameString可选

客户的中间名

last_nameString必填

客户的姓

typeString必填

预定义的证件类型。仅 bank_account是目前支持的

valueString必填

客户的证件号码

countryString必填

证件签发机构的 2 位国家代码

bvnString必填

客户的银行验证号（BVN）

bank_codeString必填

你可以调用 查询银行列表接口。（在以下情况为必填：type为 bank_account）

account_numberString必填

客户的银行账号。（当 type为 bank_account）

你可以调用[查询银行列表]接口获取银行代码列表。（当 type 为 bank_account 时为必填）
请求示例cURL
letter country code of identification issuer
响应示例JSON
#!/bin/sh
url="https://api.paystack.co/customer/{customer_code}/identification"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"country": "NG",
"type": "bank_account",
"account_number": "0123456789",
"bvn": "20012345677",
"bank_code": "007",
"first_name": "Asta",
"last_name": "Lavista"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
{
"status": true,
"message": "Customer Identification in progress"
}

将客户加入白名单/黑名单

POST /customer/set_risk_action

将集成中的客户加入白名单或黑名单

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customerString必填

客户代码或邮箱地址

risk_actionString可选

可选的风险操作之一：[ default，allow，deny]。allow（加入白名单）。deny（加入黑名单）。客户默认风险状态为 default风险操作。

发起请求以创建用于周期性交易的可复用支付授权码。
请求示例cURL
#!/bin/sh
url="https://api.paystack.co/customer/set_risk_action"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"customer": "CUS_xr58yrr2ujlft9k",
"risk_action": "allow"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST

直接借记激活扣款

PUT /customer/:id/directdebit-activation-charge

代客户对未激活的授权委托发起激活扣款

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

idinteger必填

支付授权关联的客户 ID

请求体参数（Body Parameters）

authorization_idinteger必填

从初始化响应中获取的支付授权 ID

请求示例cURL
#!/bin/sh
curl https://api.paystack.co/customer/{id}/directdebit-activation-charge
-H "Authorization: Bearer YOUR_SECRET_KEY"
-H "Content-Type: application/json"
-d '{
"authorization_id" : 1069309917
}'
-X PUT
响应示例JSON
{
  "status": true,
  "message": "Mandate is queued for retry"
}

停用支付授权

POST /customer/authorization/deactivate

停用任一支付渠道的支付授权

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

authorization_codeString必填

要停用的支付授权码

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/customer/authorization/deactivate"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"authorization_code": "AUTH_xxxIjkZVj5"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Authorization has been deactivated"
}
