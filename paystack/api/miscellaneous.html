其他接口

其他接口是一组辅助 API，用于为其他接口提供更多细节数据。

查询银行列表

GET /bank

获取所有支持的银行及其属性列表

查询参数（Query Parameters）

countryString必填

要获取支持银行列表的国家，可选值：ghana，kenya，nigeria，south africa

use_cursorboolean必填

是否在该接口启用游标分页

perPageInteger必填

每页返回的对象数量，默认 50，单页最多 100 条。

pay_with_bank_transferBoolean可选

布尔标记，用于筛选客户可用于转账完成支付的银行

pay_with_bankBoolean可选

布尔标记，用于筛选客户可直接付款的银行

enabled_for_verificationBoolean可选

布尔标记，用于筛选南非支持账号校验的银行。需要与以下参数组合使用：currency或 country筛选条件。

nextString可选

游标，表示你当前在列表中的位置，可用于获取下一页数据

previousString可选

游标，表示你当前在列表中的位置；在首次请求下一页后，可用它获取上一页数据

gatewayString可选

银行的网关类型，可取：[emandate, digitalbankmandate]

typeString可选

金融渠道类型。加纳渠道请使用mobile_money用于移动钱包渠道，或ghipss用于银行渠道

currencyString可选

以下之一：支持的货币的最小单位

include_nip_sort_codeBoolean可选

布尔标记，用于返回尼日利亚银行及其 nip institution code。返回值可用于在 NIP 中识别机构。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bank"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET

查询州/省列表（AVS）

GET /address_verification/states

获取某个国家的州/省列表，用于地址校验

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

countryString必填

要列出州/省的国家代码，可选值：US，CA，GB

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/address_verification/states?country=CA"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
响应示例JSON
{
  "status": true,
  "message": "States retrieved",
  "data": [
    {
      "name": "Alberta",
      "slug": "alberta",
      "abbreviation": "AB"
    },
    {
      "name": "British Columbia",
      "slug": "british-columbia",
      "abbreviation": "BC"
    }
  ]
}
