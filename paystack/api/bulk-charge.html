批量扣款

批量扣款 API 用于向你的客户创建和管理多笔周期性扣款。

发起批量扣款

POST /bulkcharge

传入包含支付授权码与金额的对象数组（金额使用[支持的货币]格式），以便我们按批次处理交易。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

(no name )Array必填

扣款对象列表，每个对象包含 authorization，amount和 reference

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bulkcharge"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
[
{"authorization": "AUTH_ncx8hews93", "amount": 2500, "reference": "dam1266638dhhd"},
{"authorization": "AUTH_xfuz7dy4b9", "amount": 1500, "reference": "dam1266638dhhe"}
]
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Charges have been queued",
  "data": {
    "batch_code": "BCH_rrsbgwb4ivgzst1",
    "reference": "bulkcharge-1663150565684-p18nyoa68a",
    "id": 66608171,
    "integration": 463433,
    "domain": "test",
    "status": "active",
    "total_charges": 2,
    "pending_charges": 2,
    "createdAt": "2022-09-14T10:16:05.000Z",
    "updatedAt": "2022-09-14T10:16:05.000Z"
  }
}

查询批量扣款批次列表

GET /bulkcharge

列出该集成创建的全部批量扣款批次，状态包括 active、paused 或 complete

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的转账页码，未指定时默认 1。

fromDatetime可选

开始列出批次的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出批次的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bulkcharge"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
响应示例JSON
{
  "status": true,
  "message": "Bulk charges retrieved",
  "data": [
    {
      "domain": "test",
      "batch_code": "BCH_1nV4L1D7cayggh",
      "status": "complete",
      "id": 1733,
      "createdAt": "2017-02-04T05:44:19.000Z",
      "updatedAt": "2017-02-04T05:45:02.000Z"
    }
  ],
  "meta": {
    "total": 1,
    "skipped": 0,
    "perPage": 50,
    "page": 1,
    "pageCount": 1
  }
}

查询批量扣款批次

GET /bulkcharge/:id_or_code

该接口用于查询指定批次代码，并通过 total_charges 与 pending_charges 属性返回处理进度等信息。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

id_or_codeString必填

要查询批次的扣款 ID 或代码。

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bulkcharge/{id_or_code}"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
响应示例JSON
{
  "status": true,
  "message": "Bulk charge retrieved",
  "data": {
    "domain": "test",
    "batch_code": "BCH_180tl7oq7cayggh",
    "status": "complete",
    "id": 17,
    "total_charges": 0,
    "pending_charges": 0,
    "createdAt": "2017-02-04T05:44:19.000Z",
    "updatedAt": "2017-02-04T05:45:02.000Z"
  }
}

查询批次内的扣款

GET /bulkcharge/:id_or_code/charges

该接口用于查询指定批次代码下的扣款记录，支持分页参数，也可按状态筛选。扣款状态包括 pending、success 或 failed。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

id_or_codeString必填

要查询扣款记录的批次 ID 或代码。

查询参数（Query Parameters）

statusString必填

取以下任一值：pending，success或 failed

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的转账页码，未指定时默认 1。

fromDatetime可选

开始列出扣款记录的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出扣款记录的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bulkcharge/{id_or_code}/charges"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET

暂停批量扣款批次

GET /bulkcharge/pause/:batch_code

使用该接口暂停批次处理

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

batch_codeString必填

要暂停的批量扣款批次代码

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/bulkcharge/pause/{batch_code}"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET
响应示例JSON
{
  "status": true,
  "message": "Bulk charge batch has been paused"
}
