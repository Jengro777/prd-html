争议

争议 API 用于在集成中管理交易争议。

查询争议列表

GET /dispute

查询针对你发起的争议列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

fromDate必填

开始列出争议的起始时间，例如 2016-09-21

toDate必填

停止列出争议的结束时间，例如 2016-09-21

perPageInteger可选

指定每页返回的记录数，未指定时默认 50。

pageInteger可选

指定要查看的争议页码，未指定时默认 1。

transactionString可选

交易 ID

statusString可选

争议状态，可选值：{ awaiting-merchant-feedback | awaiting-bank-feedback | pending | resolved }

#!/bin/sh
url="https://api.paystack.co/dispute"
authorization="Authorization: Bearer YOUR_SECRET_KEY"

curl "$url" -H "$authorization" -X GET

提交证据

POST /dispute/:id/evidence

提交争议举证材料

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customer_emailString必填

客户邮箱

customer_nameString必填

客户姓名

customer_phoneString必填

客户手机号

service_detailsString必填

涉及的服务详情

delivery_addressString可选

收货地址

delivery_dateDate可选

配送日期的 ISO 8601 表示（YYYY-MM-DD）

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/dispute/:id/evidence"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{ "customer_email": "cus@gmail.com",
"customer_name": "Mensah King",
"customer_phone": "0802345167",
"service_details": "claim for buying product",
"delivery_address": "3a ladoke street ogbomoso"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST

处理争议

PUT /dispute/:id/resolve

在集成中处理争议

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

idString必填

争议 ID

请求体参数（Body Parameters）

resolutionString必填

争议处理结果，可选值：{ merchant-accepted | declined }。

messageString必填

处理原因

refund_amountInteger必填

退款金额，使用 支持的货币的最小单位

导出争议

GET /dispute/export

导出集成中的争议记录

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

fromDate必填

开始列出争议的起始时间，例如 2016-09-21

toDate必填

停止列出争议的结束时间，例如 2016-09-21

perPageInteger可选

指定每页返回的记录数，未指定时默认 50。

pageInteger可选

指定要查看的争议页码，未指定时默认 1。

transactionString可选

交易 ID

statusString可选

争议状态，可选值：{ awaiting-merchant-feedback | awaiting-bank-feedback | pending | resolved }
