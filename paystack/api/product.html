商品

商品 API 用于在集成中创建和管理商品库存。

创建商品

POST /product

在你的集成中创建商品

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

nameString必填

商品名称

descriptionString必填

商品的描述

priceInteger必填

价格应使用 支持的货币的最小单位

currencyString必填

货币（其中设置了价格）

unlimitedBoolean可选

设为 true（商品库存无限时使用）。留空或设为 false（商品库存有限时使用）

quantityInteger可选

库存商品数量。在以下情况使用：unlimited为 false

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/product"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"name": "Puff Puff",
"description": "Crispy flour ball with fluffy interior",
"price": "5000",
"currency": "NGN",
"unlimited": false,
"quantity": 100
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON

查询商品列表

GET /product

查询集成中的商品列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查看的页码，未指定时默认 1。

fromDatetime可选

开始列出商品的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出商品的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

#!/bin/sh
url="https://api.paystack.co/product"
