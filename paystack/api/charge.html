扣款

扣款 API 允许你在发起支付时指定所使用的支付渠道。

创建扣款

POST /charge

集成你选择的[支付渠道]，发起一笔支付。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

emailString必填

客户的邮箱地址

amountString必填

金额，使用 支持的货币的最小单位

split_codeString可选

此前创建的分账代码，例如 SPL_98WF13Eb3w

subaccountString可选

拥有该笔款项的子账户代码，例如 ACCT_8f4s1eq7ml6rlzj

transaction_chargeInteger可选

用于覆盖单笔分账配置的金额。设置后，该金额将全额进入主账户，不受分账配置影响。

bearerString可选

使用该参数指定由谁承担交易手续费，可选值：account或 subaccount（默认取 account）。

bankObject可选

包含待扣款客户的银行账户信息

bank_transferObject可选

用于设置 Pay with Transfer（PwT）与 Pesalink 渠道的参数。

ussdObject可选

要扣款的 USSD 类型，目前仅在尼日利亚支持

mobile_moneyObject可选

移动钱包信息，目前在加纳、肯尼亚和科特迪瓦支持。

qrObject可选

包含用于完成支付的服务商信息，目前仅在南非支持。

eftObject可选

包含服务商信息，目前仅在南非支持。

capitec_payobject可选

账户持有人标识。

authorization_codeString可选

用于扣款的支付授权码（对银行账户扣款时无需传入）

pinString可选

4 位 PIN 码（需配合不可复用的支付授权码使用）

metadataObject可选

用于传递支付后流程所需的附加信息

referenceString可选

唯一的交易 reference。仅允许 -，.`，=以及字母数字字符。

device_idString可选

用户支付设备的唯一标识。仅 -，.`，=以及字母数字字符。

addressString必填

用户提交的地址

referenceString必填

进行中交易的 reference

cityString必填

用户提交的城市

stateString必填

用户提交的州/省

zipcodeString必填

用户提交的邮编

#!/bin/sh
url="https://api.paystack.co/charge/submit_address"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{

"address": "140 N 2ND ST",
"city": "Stroudsburg",
"state": "PA",
"zip_code": "18360"
}'

查询待处理扣款

GET /charge/:reference

当扣款状态返回 pending，或调用任一 /charge 接口出现异常时，请等待至少 10 秒后再查询状态是否变化。不要过早查询，否则会得到过多 pending 状态。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

referenceString必填

要校验的 reference
