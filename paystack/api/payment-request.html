付款请求

付款请求 API 用于管理商品与服务的收款请求。

创建付款请求

POST /paymentrequest

在你的集成中为某笔交易创建付款请求

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

请求体参数（Body Parameters）

customerString必填

客户 ID 或代码

amountInteger必填

付款请求金额。当未指定行项目与税额时应使用该参数。

redirect_urlString可选

指定支付成功后 Paystack 跳转的 URL

metadataString可选

自定义数据的 JSON 字符串，参见 Metadata 元数据页面了解更多。

due_dateDatetime可选

请求到期日的 ISO 8601 表示

descriptionString可选

付款请求的简短描述

line_itemsArray of Strings可选

行项目数组，格式为 [{"name":"item 1", "amount":2000, "quantity": 1}]

taxArray of Strings可选

要收取的税费数组，格式为 [{"name":"VAT", "amount":2000}]

currencyString可选

指定 结算货币（付款请求的币种），默认 NGN。

send_notificationBoolean可选

表示 Paystack 是否向客户发送邮件通知。默认值为 true

draftBoolean可选

是否将请求保存为草稿。默认 false，且会覆盖 send_notification

has_invoiceBoolean可选

设为 true（用于创建草稿付款请求；若未提供编号会自动生成自增编号），即使没有 line_items或 tax传入

invoice_numberInteger可选

付款请求的数值编号。付款请求从 1 开始自增；该字段可覆盖 Paystack 的默认取值，后续付款请求将从此值继续自增。

split_codeString可选

分账的代码，例如 SPL_98WF13Eb3w

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/paymentrequest"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{ "description": "a test invoice",
"line_items": [
{"name": "item 1", "amount": 20000},
{"name": "item 2", "amount": 20000}
],
"tax": [
{"name": "VAT", "amount": 2000}
],
"customer": "CUS_xwaj0txjryg393b",
"due_date": "2020-07-08"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X POST
响应示例JSON
{
  "status": true,
  "message": "Payment request created",
  "data": {
    "id": 3136406,
    "domain": "test",
    "amount": 42000,

    "due_date": "2020-07-08T00:00:00.000Z",
    "has_invoice": true,

查询付款请求列表

GET /paymentrequest

查询集成中的付款请求列表

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

查询参数（Query Parameters）

perPageInteger必填

指定每页返回的记录数，未指定时默认 50。

pageInteger必填

指定要查询的付款请求页码，未指定时默认 1。

customerString必填

按客户 ID 筛选

statusString必填

按付款请求状态筛选

currencyString必填

按以下条件筛选：结算货币

include_archiveString必填

是否显示已归档的付款请求

fromDatetime可选

开始列出付款请求的起始时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

toDatetime可选

停止列出付款请求的结束时间，例如 2016-09-24T00:00:05.000Z，2016-09-21

更新付款请求

PUT /paymentrequest/:id_or_code

更新集成中付款请求的信息

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

content-typeString必填

取值设为 application/json

路径参数（Path Parameters）

id_or_codeString必填

付款请求 ID 或 Slug

请求体参数（Body Parameters）

customerString必填

客户 ID 或代码

amountInteger必填

付款请求金额。仅在忽略行项目与税额时有意义；若两者都未提供，接口会给出友好提示。

due_dateDatetime可选

请求到期日的 ISO 8601 表示

descriptionObject可选

付款请求的简短描述

line_itemsArray of Strings可选

行项目数组，格式为 [{"name":"item 1", "amount":2000}]

taxArray of Strings可选

要收取的税费数组，格式为 [{"name":"VAT", "amount":2000}]

currencyString可选

指定 结算货币（付款请求的币种），默认 NGN。

send_notificationBoolean可选

表示 Paystack 是否向客户发送邮件通知。默认值为 true

draftBoolean可选

是否将请求保存为草稿。默认 false，且会覆盖 send_notification

invoice_numberInteger可选

付款请求的数值编号。付款请求从 1 开始自增；该字段可覆盖 Paystack 的默认取值，后续付款请求将从此值继续自增。

split_codeString可选

分账的代码，例如 SPL_98WF13Eb3w

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/paymentrequest/:id_or_code"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"
data='{
"description": "Update test invoice",
"due_date": "2017-05-10"
}'

curl "$url" -H "$authorization" -H "$content_type" -d "$data" -X PUT

归档付款请求

POST /paymentrequest/archive/:code

用于归档付款请求。归档后将不再出现在列表查询结果中，校验时也不会返回。

请求头（Headers）

authorizationString必填

取值设为 Bearer SECRET_KEY

路径参数（Path Parameters）

codeString必填

付款请求代码

请求示例cURL
#!/bin/sh
url="https://api.paystack.co/paymentrequest/archive/:id_or_code"
authorization="Authorization: Bearer YOUR_SECRET_KEY"
content_type="Content-Type: application/json"

curl "$url" -H "$authorization" -H "$content_type" -X POST
响应示例JSON
{
  "status": true,
  "message": "Payment request has been archived"
}
