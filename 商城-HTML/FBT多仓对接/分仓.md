# OMS仓库分配评分模型

## 版本：2.0
## 更新日期：2026-04-28

---

## 一、 模型概述

本模型用于OMS（订单管理系统）进行仓库分配决策。系统会遍历所有候选仓库，先通过硬性过滤条件排除不可用的仓库，再对剩余仓库进行4个维度的加权评分，最终选出得分最高的仓库作为发货仓。

### 评分维度与权重（总计100%）

| 维度 | 权重 | 核心逻辑 |
|------|------|----------|
| 地理距离优先 | 25% | 距离越近，得分越高 |
| 物流成本最优 | 30% | 运费越低，得分越高 |
| 库存水位优先 | 25% | 库存相对安全线越充足，得分越高 |
| 仓库负荷均衡 | 20% | 分配后预估负载越低，得分越高 |

---

## 二、 通用符号约定

| 符号 | 含义 |
|------|------|
| `N` | 本单待分配的货品总数量 |
| `i` | 当前计算的候选仓库编号 |
| `地理权重` | 0.25（可配置） |
| `成本权重` | 0.30（可配置） |
| `库存权重` | 0.25（可配置） |
| `负荷权重` | 0.20（可配置） |

**约束：** 四项权重之和必须等于 100%。

---

## 三、 硬性过滤（前置条件）

> **注意：** 以下条件必须**全部满足**，仓库才可进入评分环节。任一条件不满足，该仓库直接被排除。

| 过滤条件 | 判断公式 | 说明 |
|----------|----------|------|
| 库存充足 | `可售库存_i ≥ N` | 可用库存必须满足本单需求量 |
| 负荷有余量 | `(当前负荷_i + N) ≤ 最大负荷_i` | 分配后不能超出仓库最大负荷能力 |
| 距离不超绝对上限 | `距离_i ≤ 绝对距离上限` | 超出绝对距离的仓库不再考虑 |
| 运费不超绝对上限 | `运费_i ≤ 绝对运费上限` | 运费超出可承受范围的仓库不再考虑 |

> 若**所有仓库均未通过硬性过滤**，则进入异常处理流程（如：选择距离最近/运费最低的仓库超量分配，或转人工审核）。

---

## 四、 评分公式（含安全保护）

### 4.1 地理距离优先

**逻辑：** 距离越近，得分越高。使用候选仓库中的相对距离进行归一化。

```
当前最大距离 = MAX(所有候选仓库的距离)

-- 保护：若所有候选仓库距离均为0
若 当前最大距离 = 0：
    地理得分_i = 地理权重 × 100

否则：
    -- 归一化到 [0, 1]，再乘以权重分，下限为0
    地理得分_i = MAX(0, 1 - 距离_i / 当前最大距离) × 地理权重 × 100
```

**修正点解析：**
- **分母为0保护**：当距离全为0时，直接赋予满分。
- **下限保护**：使用 `MAX(0, ...)` 避免因距离超过最大距离而产生负数。

---

### 4.2 物流成本最优

**逻辑：** 运费越低，得分越高。使用候选仓库中的相对运费进行归一化。

```
当前最高运费 = MAX(所有候选仓库的运费)

-- 保护：若所有候选仓库运费均为0
若 当前最高运费 = 0：
    成本得分_i = 成本权重 × 100

否则：
    -- 归一化到 [0, 1]，再乘以权重分，下限为0
    成本得分_i = MAX(0, 1 - 运费_i / 当前最高运费) × 成本权重 × 100
```

**修正点解析：**
- **分母为0保护**：当运费全为0（如免邮）时，直接赋予满分。
- **下限保护**：使用 `MAX(0, ...)` 确保得分非负。

---

### 4.3 库存水位优先

**逻辑：** 库存相对于安全库存线越充裕，得分越高。为避免该维度得分无限放大，加入上限截断。

**参数：** `上限值 = 1.5`（可配置，表示库存达到安全线的1.5倍即视为满分）

```
-- 步骤1：计算库存水位系数
若 安全库存线_i = 0：
    库存水位系数_i = 上限值   （视为库存充足）
否则：
    库存水位系数_i = MIN(上限值, 可售库存_i / 安全库存线_i)

-- 步骤2：映射到得分区间
库存得分_i = (库存水位系数_i / 上限值) × 库存权重 × 100
```

**修正点解析：**
- **分母为0保护**：当安全库存线为0时，直接视为库存充足，给予上限值。
- **上限截断**：使用 `MIN(上限值, ...)` 防止库存超高时分数无限膨胀，淹没其他维度。
- **得分归一化**：除以 `上限值` 确保满分等于 `库存权重 × 100`，不会超出。

---

### 4.4 仓库负荷均衡

**逻辑：** 使用**分配后的预估负荷**计算负载率，负载率越低得分越高。这能避免多个订单同时涌入同一个看似空闲的仓库。

```
-- 步骤1：计算分配后的预估占用率
若 最大负荷_i = 0：
    预估占用率_i = 1 （视为满载，不可用）
否则：
    预估占用率_i = (当前负荷_i + N) / 最大负荷_i

-- 步骤2：计算得分（预估占用率 ≤ 1 已由硬性过滤保证）
-- 占用率越低，得分越高
负荷得分_i = (1 - 预估占用率_i) × 负荷权重 × 100
```

**修正点解析：**
- **分母明确**：`最大负荷_i` 指**该仓库自身的最大负荷能力**，而非所有仓库的总和。
- **预估负荷**：使用 `(当前负荷_i + N)` 计算分配后的状态，而非当前状态，更具前瞻性。
- **分母为0保护**：当最大负荷为0时，预估占用率设为1，得分自然为0。
- **自然非负**：由于硬性过滤已保证 `(当前负荷 + N) ≤ 最大负荷`，因此 `预估占用率 ≤ 1`，得分自然 ≥ 0。

---

## 五、 总得分计算与仓库选择

```
总得分_i = 地理得分_i + 成本得分_i + 库存得分_i + 负荷得分_i
```

### 决策规则：

1. 对所有通过**硬性过滤**的候选仓库计算 `总得分`。
2. 选择 **总得分最高** 的仓库作为本次分配的目标仓库。
3. 若出现最高分并列：
   - 优先取成本得分更高者。
   - 若仍并列，优先取库存得分更高者。
   - 若仍并列，任意选一个。

## 六、 参数配置表

| 参数名称 | 建议默认值 | 说明 |
|----------|------------|------|
| 地理权重 | 25% | 四项权重之和必须为100% |
| 成本权重 | 30% | 一般成本是最敏感的维度 |
| 库存权重 | 25% | 确保库存充足的发货 |
| 负荷权重 | 20% | 平衡各仓压力 |
| 库存水位上限 | 1.5 | 库存达到安全线的1.5倍即满分 |
| 绝对距离上限 | 5000km | 可根据实际业务调整 |
| 绝对运费上限 | 50元 | 根据订单利润可承受范围配置 |

---

## 七、 异常处理

当**没有仓库**通过硬性过滤时，执行以下降级策略（按优先级）：

1. **忽略绝对运费上限**，重新过滤；若仍无仓库，则：
2. **忽略绝对距离上限**，重新过滤；若仍无仓库，则：
3. **忽略负荷限制**（允许超量分配），选择可售库存 ≥ N 的仓库中总得分最高者；
4. 若仍无仓库满足库存条件，转 **人工审核**。

## 八、 示例验证

### 示例数据

| 仓库 | 距离(km) | 运费(元) | 可售库存 | 安全库存线 | 当前负荷 | 最大负荷 |
|------|----------|----------|----------|------------|----------|----------|
| A | 200 | 15 | 500 | 300 | 400 | 1000 |
| B | 800 | 25 | 800 | 300 | 600 | 1000 |
| C | 1500 | 40 | 600 | 300 | 200 | 1000 |

**订单需求量 N = 100**

### 硬性过滤检查

| 仓库 | 库存≥100 | 负荷+100≤1000 | 距离≤5000 | 运费≤50 | 结果 |
|------|----------|---------------|-----------|---------|------|
| A | ✅ | ✅ | ✅ | ✅ | 通过 |
| B | ✅ | ✅ | ✅ | ✅ | 通过 |
| C | ✅ | ✅ | ✅ | ✅ | 通过 |

### 评分计算（权重：地理25%、成本30%、库存25%、负荷20%，上限值=1.5）

**仓库A：**
- 地理分 = (1 - 200/1500) × 25 = 21.67
- 成本分 = (1 - 15/40) × 30 = 18.75
- 库存系数 = MIN(1.5, 500/300) = 1.5
- 库存分 = (1.5/1.5) × 25 = 25.00
- 预估占用率 = (400+100)/1000 = 0.50
- 负荷分 = (1 - 0.50) × 20 = 10.00
- **总得分 = 75.42**

**仓库B：**
- 地理分 = (1 - 800/1500) × 25 = 11.67
- 成本分 = (1 - 25/40) × 30 = 11.25
- 库存系数 = MIN(1.5, 800/300) = 1.5
- 库存分 = (1.5/1.5) × 25 = 25.00
- 预估占用率 = (600+100)/1000 = 0.70
- 负荷分 = (1 - 0.70) × 20 = 6.00
- **总得分 = 53.92**

**仓库C：**
- 地理分 = (1 - 1500/1500) × 25 = 0.00
- 成本分 = (1 - 40/40) × 30 = 0.00
- 库存系数 = MIN(1.5, 600/300) = 1.5
- 库存分 = (1.5/1.5) × 25 = 25.00
- 预估占用率 = (200+100)/1000 = 0.30
- 负荷分 = (1 - 0.30) × 20 = 14.00
- **总得分 = 39.00**

### 结论
**选择仓库A（总得分75.42最高）** ✅
