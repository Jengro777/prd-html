控制台概览

干线路线

连接主要转运中心的骨干网络，通常跨越多个省市，运输大批量货物。

示例： 北京转运中心 → 上海转运中心
支线路线

连接转运中心与城市配送中心的次级网络，覆盖中等距离的运输需求。

示例： 上海转运中心 → 杭州分拨中心
接驳路线

短距离的转运路线，通常在分拣中心与营业部之间进行货物转运。

示例： 浦东分拣中心 → 陆家嘴营业部
循环接驳

从分拣中心出发，经过多个配送点后返回起点的循环配送路线。

示例： 分拣中心 → 站点A → 站点B → 分拣中心
